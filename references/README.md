# お手本の置き場

画面の見た目を作るときのお手本（良いと思った画面）を集める所。
集めたものは design-ref に保存され、見た目を作るときと、作ったあとの見比べに使う。

## 置き方

1. スクリーンショットを `inbox/` に入れる（PNG・JPEG・WebP・PDF）
2. ひとことメモを付けたいときは、同じ名前の `.txt` を横に置く（なくてもよい）

```
inbox/
  ableton-arrangement.png
  ableton-arrangement.txt   ← 「行が細くて、たくさん並んでも読める」など
```

- ファイル名がそのままお手本の名前になる。製品名と画面の名前にしておくと後で探しやすい
- メモの1行目は「なぜ良いか」として使う。2行目に `タグ: 時間軸, 照明卓` のように書くと、タグも付く
- 画面全体でも、一部の切り抜きでもよい

## 置いた意味

`inbox/` に入れただけでは保存しない。**保存の前に、毎回 Claude が聞く。**
置いた画像の一覧（名前・メモ・タグ）を見せるので、保存してよいものを答える。

## 保存の流れ（Claude がやること）

1. `inbox/` の画像を一覧にして、保存してよいかを聞く。よいと答えたものだけを、メモと一緒に design-ref へ保存する（媒体：画面、タグ「道具の画面」を足す）。答えのなかったものは `inbox/` に残す
2. 保存したら、画像とメモを `saved/` へ移し、`saved/log.tsv` に1行足す（ファイル名・design-ref の id・名前・日付）
3. 同じ名前がすでに `saved/log.tsv` にあれば、保存しないで知らせる（二重に保存しない）

消したいときは、design-ref 側の扱いを Claude に頼む（`saved/` から消しても design-ref からは消えない）。
