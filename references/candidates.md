# お手本の候補（2026-11-03 調べ）

この噴水エディタに近い「時間軸の上に機材の行が並ぶ」画面を優先して選んだ。
選んだものは、自分でスクリーンショットを撮って `inbox/` に置く（README.md）。

見る観点：余白・情報の階層・密度・並べ方。色・文言・ロゴは写さない。

## 1. grandMA3 onPC — Timecode Viewer
- 何か：大きなコンサートや劇場の照明卓。PC 版が無料
- 移せる所：左に「トラックの組 → トラック」の2段、右に時間軸。文字の表と時間軸を切り替えたり並べたりできる。噴水の「グループ → 行」と同じ形。編集の時だけ左に道具の列が出る（見る時と直す時で画面を分ける）
- 合わない所：卓の画面に合わせた大きなボタン。マウスで使うには余白が大きい所がある
- リンク：https://help.malighting.com/grandMA3/2.5/HTML/timecode_viewer.html

## 2. Ableton Live 12 — Arrangement View
- 何か：作曲・ライブ用の DAW
- 移せる所：行の高さが低く、たたむ・広げるができる。行の頭（名前と少しの操作）は狭い列にまとめる。クリップの色は「中身の色」で、画面の地はくすんだ灰色だけ（行の色は会場から来て、テーマは無彩色、という G6 の分け方と同じ）
- 合わない所：小節と拍の目盛りが前提。噴水は秒とキュー
- リンク：https://www.ableton.com/ja/manual/arrangement-view/

## 3. Finale 3D
- 何か：花火の演出ソフト。業界でよく使われる
- 移せる所：波形の上に、玉ごとに「打ち上げ → 開く → 消える」の長さの棒が並ぶ。表（スクリプト）と時間軸と 3D の3つが連動する。段階2の花火の行の形の手本になる
- 合わない所：表の画面が古い表計算ふう。色や部品は手本にしない
- リンク：https://finale3d.com/downloads/finale-3d-lite/

## 4. Depence（Syncronorm）
- 何か：噴水・照明・レーザー・花火を 3D で作るソフト。このプロジェクトが「その手前に立つ」と決めた相手
- 移せる所：場面をトラックに置く時間軸、色だけのトラック、印（マーカー）、入れ子の並び。噴水の現場の人が見慣れた形
- 合わない所：有料で、自分で撮りにくい。機能が多く、画面の密度が高すぎる所もある
- リンク：https://www.syncronorm.com/products/depence/show-control ／ https://www.syncronorm.com/industries/multimedia-fountains-neu

## 5. COBRA Show Creator
- 何か：花火の点火機メーカーの演出ソフト。ブラウザで動く
- 移せる所：波形の上にイベントを直に置く。点火までの時間・上がる時間・開いている時間を分けて見せる。ブラウザの道具なので、作り方が近い
- 合わない所：初心者向けで、密度が低い
- リンク：https://www.cobrafiringsystems.com/show_software.html

## 6. DaVinci Resolve — Fairlight／Edit
- 何か：映像の編集と音の仕上げ。無料版がある
- 移せる所：パネルの区切りを 1px の線だけで作る。トラックの頭に「何本入っているか」などの数字。時刻の数字が大きくはっきり
- 合わない所：パネルが多く、全部まねすると重くなる
- リンク：https://www.blackmagicdesign.com/jp/products/davinciresolve

## 7. QLab 5
- 何か：劇場で音・映像・照明のきっかけを出すソフト（Mac）
- 移せる所：一覧の上で「次に出るキュー」を三角で示す。状態は小さな印（動いている・止まっている・壊れている）だけ。下に選んだキューの詳細。エディタの右の詳細欄の形の手本になる
- 合わない所：時間軸の行がない。一覧が中心
- リンク：https://qlab.app/docs/v5/

## 8. disguise designer
- 何か：大きな舞台の映像を出すメディアサーバー
- 移せる所：15〜30 枚のレイヤーが重なっても読めるように、規則で色を付ける（色は意味に結びつける）
- 合わない所：映像の合成が前提。噴水の機材の行とは少し違う
- リンク：https://help.disguise.one/designer/layers/layers-overview ／ https://www.disguise.one/en/insights/blog/how-our-coloured-layers-bring-more-clarity-your-visual-programming

## おすすめ
1. **grandMA3 の Timecode Viewer**：「組 → 行 → 時間軸」の形がいちばん近い。プロの照明卓で、地は無彩色、色は状態にだけ使う
2. **Ableton Live の Arrangement View**：行を細く、たくさん並べても読める密度の手本。中身の色と画面の色を分ける考え方が G6 と同じ
3. **Finale 3D**：次の段階2（花火）の行の形まで一度に決められる。Lite は無料で撮れる

画面の中身は各社のマニュアルや製品ページの説明から調べた。実際の画面の画像は、自分で撮ったものを見て確かめる。
