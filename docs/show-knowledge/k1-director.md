## 2. 原則

確度：高＝本人の発言・一次資料／中＝業界誌・メーカー・公式PR／低＝ファン・推測。

**P1 音楽が台本。感情の筋書きを先に書いてから水を置く**
- なぜ：同期の正確さは採点項目の一部にすぎず、客が覚えているのは感情の流れだから
- 具体：Dorsey は作る前に感情の物語を描く。Jung・Horne は制作を曲から始めた。Rob Paul はサウンドトラックを骨組みと呼ぶ
- 出典：Blooloop（Dorsey）、ziggyknowsdisney、attractionsmagazine、Blooloop（Rob Paul）／確度：高（Dorsey・Jung・Horne の発言）

**P2 水は役者。機材の一覧を見せるのではなく、性格と役を与える**
- なぜ：「噴水がいっぱい動いた」は記憶に残らない。役があると客は感情を重ねられる
- 具体：Davison は水を「生きた役者」と呼び、オレンジの噴水 Little Squirt に性格とユーモアを持たせた。WoC の初版では、この噴水が途中と最後に再登場して全体をつなぐ
- 出典：https://archive.wdwnt.com/?p=13755 、場面一覧 https://archive.wdwnt.com/tag/steven-davison/ ／確度：高

**P3 字義どおりに描かず、感情を描く**
- なぜ：水で具体的な絵を描くと、見劣りする再現になりやすい
- 具体：Fuller は GoT 版について「感情を届けたい」と述べた。Dorsey は意味を言い切らない。ECA2 も語りに頼らない作り
- 出典：WJLA（AP）、Blooloop（Dorsey）、ECA2／確度：高

**P4 楽に見せる。苦労が見えたら負け**
- なぜ：機材の限界や段取りが見えた瞬間に、客は「機械」を見始める
- 具体：Davison は WoC をフィギュアスケートにたとえ、「アイススケートのような」効果を目指した。Disneyland Forever では、レーザーや投影機のことを客に考えさせないよう作った
- 出典：Live Design（検索要約のみ）、MousePlanet／確度：中

**P5 冒頭の一瞬でつかむ。ただし「静かに始める」のが噴水の定石**
- なぜ：客の集中は冒頭が一番高い。一方で、最初から最大にすると後で上がる余地がなくなる
- 具体：Davison は冒頭から引き込むことを狙う。Kopik によれば Bellagio の通常のショーはゆっくり始まり、Tiësto 版は例外として爆発で始めた。つまり「静かだが目を奪う一点」で始めるのが基本で、爆発で始めるのは曲がそれを要求するときだけ
- 出典：WDWNT D23、World Casino Directory／確度：高（どちらも本人の発言）

**P6 強さが続く曲ほど、疲れさせない工夫がいる**
- なぜ：同じ強さが続くと目が慣れ、山場が山場に見えなくなる
- 具体：Kopik は GoT 版で「ずっと強いのに疲れさせない」ことを課題に挙げた。PyroJam の課題文は「感情の山と谷」を求める
- 出典：WJLA（AP）、https://finale3d.com/contests/pyrojam-2026/ ／確度：高

**P7 山場は一つにしない。「第一のフィナーレ」を置いてから本当の終わりへ**
- なぜ：一度「終わった」と思わせてからもう一段上げると、最後の印象が強くなる
- 具体：Disneyland Forever では、雪の場面の花火を Davison 自身が「第一のフィナーレ」と呼ぶ。WoC の初版も、暗い悪役の場面 → 光の変身 → フィナーレ → アンコールの順に、暗い谷を挟んで二段で上げる
- 出典：MousePlanet、WDWNT 場面一覧／確度：中〜高

**P8 最後と頂点で記憶が決まる（ピーク・エンドの法則）**
- なぜ：人は体験を、平均ではなく「一番強い瞬間」と「終わり方」で評価し、長さはほとんど影響しない（Kahneman ら）
- 具体：最後の数秒にお金を使う。途中を長くしても評価は上がらない。Rob Paul も「もっと見たい」で終えるよう勧める。花火の採点にも「最後の仕掛け（bouquet final）」という独立した項目がある（モナコ）
- 出典：https://en.wikipedia.org/wiki/Peak%E2%80%93end_rule 、https://pmc.ncbi.nlm.nih.gov/articles/PMC6668632 、モナコ https://monacolife.net/austrians-win-closely-contested-fireworks-competition__trashed/ ／確度：法則そのものは高。ショーへの当てはめは推測

**P9 物語は額縁で始めて額縁で閉じる（ブックエンド）**
- なぜ：同じ絵で始めて終わると、客は「旅をして帰ってきた」と感じる
- 具体：Disneyland Forever は、冒頭のオレンジ畑に最後に戻る。WoC 初版は Tinker Bell と Little Squirt が冒頭と最後に出る
- 出典：MousePlanet、WDWNT 場面一覧／確度：中

**P10 選曲は会場の品位に合わせる**
- なぜ：噴水は街や施設の顔で、ふざけた曲はそれを笑い物にする
- 具体：Kopik は Dubai Fountain で、振り付けやすくても品位を損なう曲を却下した
- 出典：The National／確度：高

**P11 色は控えるほど上品に見える**
- なぜ：色を増やすほど「派手」には見えるが、「格」は下がりやすい
- 具体：Bellagio は色付きではなく白の照明を選んだ。白のほうが上品だという設計者の判断による（Wikipedia の記述で、出典は二次）
- 出典：https://en.wikipedia.org/wiki/Fountains_of_Bellagio ／確度：中

**P12 どこから見ても成立させ、場所ごとに違う発見を残す**
- なぜ：客席は広く、中央以外の客も同じお金を払っている
- 具体：WoC は中央が一番深く見え、後方でも成立するように作られた。Disneyland Forever は見る場所ごとに違う効果を見せる。PyroJam の技術点は、発射位置と空間の使い方を見る
- 出典：WDWNT D23、MousePlanet、PyroJam 2026／確度：中〜高

**P13 時間は手間の量に比例する。短いショーほど1秒あたりの密度を上げられる**
- なぜ：多場面ショーは1場面が短く浅くなりがち
- 具体：Bellagio では、2分の音楽に最大1週間かける。Dubai は1曲に2〜4週間（シミュレーションの後、現地で調整）
- 出典：Wikipedia（Bellagio）、The National／確度：中

**P14 機材の種類を増やして単調さを防ぐ。ただし削っても成り立つ骨格にする**
- なぜ：一つの効果に頼ると単調になる。一方、高価な要素は運用で真っ先に削られる
- 具体：Luminaria が花火頼みだった反省から、WoC は要素の種類を増やした。Rob Paul は高価な消耗品を「無くても成立する」ように作れと言う
- 出典：WDWNT D23、Blooloop（Rob Paul）／確度：中

どの大会にも共通するのは「同期」「選曲と編集」「全体の構成と印象」の3つ。PyroJam では、同期より全体の印象と構成の点が重い（合わせて55点）。正確に合っていても、感情の山と谷がなければ勝てない。
「品のよい短い無音は一流の作品でよくある」という Finale 3D の記述が引用されていたが、原文は確認できなかった（確度：低）。

日本の花火競技大会（土浦のスターマインの部：音楽と400発以内でストーリー性のある演出）は、公開された採点表を見つけられなかった。

## 4. 1曲ショーと多場面ショーの違い

| | 1曲ショー（Bellagio・Dubai 型） | 多場面ショー（WoC 型） |
| --- | --- | --- |
| 長さ | 1曲＝1ショー。Bellagio の GoT 版は3分半（AP）。30分おきに繰り返す | WoC 21〜30分（版による）、アオ 20〜25分、ビリーヴ約30分 |
| 骨格 | 曲の形式（イントロ・主題・展開・終止）がそのまま構成になる | 場面（初版 WoC は約18場面）を、谷と山の並べ方で構成する |
| 物語 | 感情の流れだけ。キャラクターは立てない | 案内役（Little Squirt、アオ）と額縁で場面をつなぐ |
| 色 | 曲全体で色の幅を小さく（Bellagio は白）。場面を色で分けない | 場面ごとに色を変える |
| 映像 | 使わない | 水幕に人物と物語を映す |
| 山場 | 主山場1つ（多くは終盤）＋小山 | 「第一のフィナーレ」＋本当のフィナーレ＋アンコール |
| 開始 | 静かな一点から（Kopik によれば通常はゆっくり始まる） | 前説・オープニングファンファーレ（例：WoC の主題歌とレーザー） |

1曲ショーの構成は推測を含む。WET の構成論を語った一次資料は見つからず、上の整理は Kopik の発言と公開された事実からの推定。

## 6. やってはいけないこと

1. **最初から全機材を出す**：上がる余地がなくなる。Bellagio も通常は静かに始める（P5）
2. **同じ強さを続ける**：GoT 版で Kopik が一番気にした点。強い曲でも谷を作る（P6）
3. **曲の場面を絵で再現しようとする**：水でできるのは感情であって、具体的な絵ではない（P3）
4. **機材の段取りを見せる**：首振りが戻る途中、水が落ちる途中、待ち時間を客に見せない（P4）
5. **フィナーレを曲の終わりで止めるだけ**：最後の数秒が評価を決める。終わりは作り込む（P8）
6. **品位に合わない曲や効果**：笑いを取る演出は、ショー全体の格を下げる（P10）
7. **中央の客席でしか成立しない構成**：端の客席からも主役が見えること（P12）
8. **高価な大技に骨格を頼る**：ガイザーを抜いても成り立つ構成にしておく（P14）
9. **3分の中に多場面ショーの作法を詰め込む**：3分で物語の場面を何度も切り替えると、どれも浅くなる。この長さなら曲の形式に従う（4章）

## 7. 3分ショーへの示唆（このシミュレーターで）

曲：ラプソディー・イン・ブルー冒頭の3分。曲の各時刻は録音で確かめること（以下の楽曲の記述は一般的な知識による推測）。

1. **型は「1曲ショー」**。WoC の多場面の作法（場面ごとの色替え・案内役・水幕の物語）は、使っても1か所だけにする。構成は曲の形式に従う：独奏 → 全奏 → ピアノ独奏 → 全奏の主題 → 終止
2. **冒頭のクラリネットのトリルとグリッサンドは「一本の役者」で始める**。暗闇から中央の chaser か grid 1本を、グリッサンドに合わせて伸ばす。この1本が「水の役者」（P2・P5）。同じ1本を最後の一発の直前にもう一度ひとりで立たせ、ブックエンドにする（P9）
3. **楽器と機材を対にする**。独奏楽器＝少数の中央機材、オーケストラ全奏＝grid 全帯と whip の隊形、ピアノ独奏＝水幕の額縁の中だけ。音量より「誰が鳴っているか」で出す機材を決める（推測）
4. **山場は二段**。中盤の全奏で「第一の山」（ガイザーは使わない。whip の扇と grid の全帯まで）→ ピアノ独奏で谷（ほぼ暗転、光点のみ）→ 終盤の全奏で主山場。ガイザーと多色は主山場と最後の一発だけ（P7）
5. **終わりを作る**。3分で切った録音が終止で終わらないなら、音のフェードに合わせて主役の一本だけを残して消す。終止があれば、最後の和音にガイザーと全帯を合わせ、余韻の間は水が落ちる様子だけを見せる（約3秒）（P8、推測）
6. **色は少なく**。曲名に合わせて「青」をホームの色にし、差し色は金か白。多色は使わないか、最後の数小節だけ（P11、推測）
7. **自己採点は PyroJam の配点で**。全体の印象30／構成25／同期15／空間15／サウンドトラック15。スキルの検査項目に「谷はあるか」「主山場は残り15〜25%にあるか」「端の客席からも成立するか」を入れる
8. **疲れさせない**。強い区間が20〜30秒以上続くときは、色・隊形・高さのどれか一つを変えて、目を新しくする（P6。秒数は推測）
