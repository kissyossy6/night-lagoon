## 実際のショーの映像分析

1秒ごとのコマを全部見て、要所は0.2秒刻みで音との時間差を測った。代表コマは `shots/show-analysis/`。

| ファイル | 対象 | 分かったこと |
| --- | --- | --- |
| [v1-bellagio-dubai.md](v1-bellagio-dubai.md) | Bellagio 3曲、Dubai 2曲（WET の1曲ショー） | 前奏は小さく1か所、入りは一撃、静かな節は1か所に絞る、最も高い水は後半に2〜3回、照明は拍と同時・水は0〜0.4秒前、色は待ち・白は全開 |
| [v2-screen-shows.md](v2-screen-shows.md) | Wings of Time、ビリーヴ！～シー・オブ・ドリームス～（水幕の物語ショー） | 水幕は全体の2〜3割で出すときは主役、人物は幅の1/3以下で霧の厚い所、周りの色替えが先で霧は2秒後、映像の光の1秒後に同じ所で実物、山場では映像を捨てる |
| [v3-structure.md](v3-structure.md) | World of Color 2010 初演、万博「アオと夜の虹のパレード」 | 場面は平均46秒、全機材は全体の15%、暗転5%、3色以上の同時は1割、山は55〜80%と最後の5%、フィナーレの多色は2秒ごとの単色切り替え |
| [../video-review.md](../video-review.md) | World of Color ONE（以前の比較） | 1場面1色＋差し色、暗転、大技は山場だけ、額縁、光点 |

測定に使ったスクリプトは調査用の一時フォルダにあり、プロジェクトには入れていない。新しい映像を分析するときは、上の文書の「測り方」を見て作り直す。
