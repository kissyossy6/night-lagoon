# 水幕を使う物語型ショーの分析（Wings of Time／ビリーヴ！）

2026-10-26。実際のショー映像2本を見て、水幕の映像と噴水・照明の組み合わせ方を拾った。時刻はすべて動画の時刻。代表コマは `shots/show-analysis/v2/`。

注意
- どちらも客席からのカメラ映像。明るい所は白く飛び、露出は自動で変わる。明るさの数値は相対的な目安
- 音はカメラのマイクで録られている。客席近くのスピーカーの音はほぼ遅れないが、花火・炎の音は距離の分だけ遅れる（100mで約0.3秒）
- 場面の物語の中身は映像からの推測が多い。推測には「推測」と書いた

## 方法

- コマ：本編を2秒ごと（WoT は舞台まわりを切り出し）、大事な所を0.5秒ごとに幅320pxで見た
- 音：モノラル22kHz。0.1秒ごとの音量（dB）と、スペクトルの増加量（spectral flux）による立ち上がり
- 映像の変化：10fpsの平均の明るさ。WoT は「水幕の位置（彫刻の上の中央）」「彫刻」「左右」に分けた
- 時間差：明るさが急に変わる所を選び、変化の始まりと、前後2秒で一番強い立ち上がりとの差を測った（`video/v2/scripts/events.py`）。ただ近くの立ち上がりを拾うだけだと、立ち上がりが1秒に約3回あるので差がばらばらになった。意味があるのは、はっきりした区切りだけ

### 水幕の映像の作り
- 地はほぼ黒。人物や鳥は暗い地に置き、霧の縁は使わない
- 人物はドームの幅の1/4〜1/3で、下半分（霧が厚い所）に置く。ドーム全体を使うのは、太陽・単色の塗り・爆発のような大きく単純な形だけ
- 明るさは高く、色は彩度の高い原色。細部は小さくなく、輪郭がはっきりしたもの（人物の上半身、鳥のシルエット）
- 動きはゆっくり。人物はほぼ止まって話す。速い動きは爆発や光の筋（場面の終わり）だけ
- 霧の外へ映像が「はみ出す」作り：彫刻・扇・柱にも同じ映像が当たり、映像が水幕より大きく見える（3:20 鳥の翼、9:10 扇、8:50 柱）

## 3. 共通則：水幕と噴水を組み合わせる

1. **水幕は時々、出すときは主役**。WoT は本編の約32%、ビリーヴは幕の数が多くても人物は約18%。水幕が出ている間、噴水は消すか額縁だけにする（WoT 7:00、12:00）
2. **霧の厚い所だけに絵を置く**。形の崩れる幕（WoT のドーム）では、人物は幅の1/4〜1/3で下半分。均一な幕（ビリーヴの矩形）なら幕いっぱい。どちらも縁にかかる細部は置かない
3. **幕全体を使うのは単純な大きい形だけ**：太陽、単色の塗り、爆発（WoT 11:36、14:32、20:06）
4. **額縁**：左右から内へ倒したアーチが幕の上を越える（WoT 11:42–12:10）、扇のアーチが小さな幕を囲む（WoT 13:16）、左右の端だけに色の柱（WoT 6:26、19:08）、幕の下を低い噴水で縁取る（ビリーヴ 13:04）
5. **映像から実物へ**：映像の中の鳥が中央で白く光り、1.0秒後に同じ位置で実物の火球（WoT 10:23→10:24）。映像を幕の外の水（扇・柱）や彫刻へ続けて、幕より大きく見せる（WoT 3:20、8:50、9:10）
6. **幕の出し方**：周りの色替えが先、霧と映像が約2秒後（WoT 2:53→2:55.5）。消すときは、幕全体を単色に塗ってから霧を下ろす（WoT 4:06）。人物は爆発や泡に変えてから消す（WoT 7:22、ビリーヴ 13:26）
7. **暗転は音の休符に合わせ、1〜2秒が基本**。大きな区切りだけ8〜12秒（WoT 2:00、14:20、ビリーヴ 12:38）。区切りは音と0.1〜0.2秒以内
8. **山場では映像を捨てる**。WoT 13:50 と 20:22 は噴水だけ（白）、ビリーヴ 21:42 は幕を青一色。山場に人物は出さない
9. **1場面1色の地**。色替えは「同じ絵の色だけ替える」（WoT 15:56 夕焼け→夜）か、4秒ごとの地の色替え（WoT 8:14–8:28）
10. **複数の幕**：ふつうは全部に同じ質感（ビリーヴ 14:26、14:50）。3面を同時に使うのは場面の頂点だけ（WoT 10:14、ドーム＋左右の扇）
11. **悪役・山場の前は最小の要素から**：暗い幕に目だけ（ビリーヴ 13:28）、暗い中の小さな人物（ビリーヴ 19:32）

## 4. World of Color（WoC）との違い

`docs/video-review.md` の WoC ONE の分析と比べた。

- **固い映写面があるか**：WoT は彫刻に常に映していて、水幕を下ろしても絵が残る。だから水幕は約3割でも場面が途切れない。WoC と今のシミュレーターには固い面がないので、水幕を消した場面はグリッドと照明の色で場面を保つ必要がある
- **水幕の数**：WoC は中央・左・右の3つの山を使い分ける。WoT は中央のドーム1つだけで、左右は扇の水膜が小さな幕の代わりになる（10:14）。ビリーヴは動く小さな幕が多く、幕の位置そのものが舞台の動き
- **人物の大きさ**：WoC・WoT は霧の幕の中央に小さく、ビリーヴは小さい幕にいっぱい。幕の質で決まる
- **額縁**：WoC はアーチで中央を囲む（C6）。WoT も同じ型（11:42）を持ち、さらに「左右端だけの色の柱」がある。今の物語の場面（ウィップ4本ずつで左右から額縁）はこの型と合っている
- **大技**：WoC のガイザーや炎は最大の山場に集中する。WoT も炎は約1分の場面に1回まとめ、一番高い柱はフィナーレだけ。ビリーヴは花火を区切りとして何度も使う（約1〜2分に1回）。花火のない今のシミュレーターでは、この「区切りの一撃」はガイザーの短い一発か白い閃光で代える（推測）

## 5. 3分のショーに直すと（目安）

- 水幕は合計で約50〜70秒（3〜4割）、出すのは2〜3回。1回は15〜40秒
- 物語の場面：中央の山（`mound[1-1]`）に暗い地の人物・舟を、幅の1/3以下で下半分に。噴水はウィップの額縁以外を消す
- 水幕を出す2秒前から周りの色を替える。消すときは山全体を単色にしてから下ろす
- 「映像から実物へ」を1回：映像の中で中央が光り、約1秒後に同じ x でガイザー
- 最後の山場は映像を消して白、または3つの山を単色に塗るだけ
- 暗転は音の休符に合わせて1〜2秒。物語に入る前だけ長め。水は落ちるのに約3秒かかるので（video-review.md）、消し始めは暗くしたい時刻の約3秒前
