# 机の噴水（実物）の作り方

2026-11-12 作成。持ち主「机サイズお願い」。シミュレーターで作った演出を、机の上の小さな本物の噴水でそのまま動かすための1台目（8台）。**部品はまだ買っていない・組んでいない**。プログラムはコンパイルまで確かめた（ESP32 Dev Module・M5Stack-ATOM）。

---

## 0. 結論（先に）

> エディタの「書き出し ▾ → Art-Net で送る…」で、パソコンから Wi-Fi で ESP32 に送り、ESP32 が 8 台の小型ポンプと LED を動かす。
>
> 1. 会場は「**机の試作（8台）**」（`src/venues/builtin/desk-8.json`）。60 × 30 cm の水槽に 8 台を 6 cm おきに一列
> 2. ESP32 のプログラムは `tools/desk-fountain/desk-fountain.ino`（ライブラリは FastLED だけ）
> 3. 組んだら、水の高さ・上がる速さ・落ちる速さを測り、シミュレーターの「ミニ噴き上げ」を実物に合わせ直す（dev-plan の B7。今は 100 m 級の見え方のまま）

## 1. つながり

```
エディタ（ブラウザ）
  └ 書き出し ▾ → Art-Net で送る…（送り先 = ESP32 の IP、ポート 6454）
      └ 開発サーバー（npm run dev）が UDP で送る（scripts/artnet-bridge.ts）
          └ Wi-Fi
              └ ESP32（tools/desk-fountain）
                  ├ PWM → MOSFET モジュール × 8 → 小型ポンプ × 8（12 V）
                  └ 信号 → LED テープ（WS2812B）× 8 粒（5 V）
```

送る値：ユニバース 1（Art-Net では 0）の番地 1 から、1 台 5 チャンネル（ポンプ・R・G・B・明るさ）。台の順は左から 1〜8（会場の `grid[0]`〜`grid[7]`）。割り当て表は「書き出し ▾ → DMX の割り当て表」でも出せる。

## 2. 部品（1台目・8台）

型番は決めていない。**買う前に、下の「選ぶときの条件」を満たすか確かめる**。

| 部品 | 数 | 選ぶときの条件 |
| --- | --- | --- |
| 水槽 | 1 | 60 × 30 cm 前後（よくある 60 cm 水槽）。水しぶきが出るので、深さに余裕のあるもの |
| 小型の水中ポンプ | 8 | 直流 12 V・ブラシレス・2 本線（PWM で回転を変えられる）。揚程（押し上げられる高さ）1 m 以上。吐出口に細いノズル（内径 2〜3 mm）をつけられるもの |
| ノズル・チューブ | 8 | ポンプの口に合う太さ。先を細くすると高く上がる |
| MOSFET モジュール | 8 | **ロジックレベル**（3.3 V で全開になる。IRF520 のモジュールは 3.3 V では開ききらないので避ける）。12 V・1 A 以上 |
| ESP32 | 1 | ESP32 Dev Module か M5Stack ATOM（Wi-Fi つき） |
| LED テープ | 8 粒 | WS2812B（または SK6812）。防水（シリコン被覆） |
| 電源 | 1 | 12 V（ポンプの電流 × 8 に余裕を足す。1 台 0.3 A なら 3 A 以上）。5 V は 12 V から降圧モジュールで作る |
| そのほか | — | 防水の箱（電気を水から離す）、配線、ヒューズ |

## 3. 配線

- ポンプ：12 V の＋ → ポンプの＋。ポンプの− → MOSFET の出力。MOSFET の入力 → ESP32 のピン（`PUMP_PINS`、左の噴水から順）
- LED：5 V・GND・信号（`LED_PIN`、既定 27）。テープの粒を左の噴水から順に、ノズルの真下へ
- **GND は全部つなぐ**（12 V・5 V・ESP32）
- 電気の部品は全部、水槽の外の防水の箱へ。水の中に入るのはポンプと LED の粒だけ
- コンセントにつなぐ電源は、漏電遮断器のついたタップから

## 4. プログラムを書き込む

1. `tools/desk-fountain/secrets.example.h` を同じ所に `secrets.h` の名前で写し、Wi-Fi の名前とパスワードを書く（`secrets.h` は GitHub に入らない）
2. Arduino IDE で `desk-fountain.ino` を開く。ボードは「ESP32 Dev Module」か「M5Stack-ATOM」、ライブラリは FastLED
3. ピンを配線に合わせる（ファイルの頭の「設定」だけ）
4. 書き込んでシリアルモニタ（115200）を開くと「Art-Net の送り先：192.168.x.x」と出る

## 5. 動かす

1. `npm run dev` で開発サーバー、エディタでプロジェクトを開き、上の帯の「会場 ▾」を「机の試作（8台）」に
2. 「書き出し ▾ → Art-Net で送る…」の送り先に ESP32 の IP を入れて送る
3. 再生すると、時間軸と同じ時刻で水と LED が動く
4. **止めるとき**：Art-Net が 1 秒来なければ、ESP32 はポンプを止める（パソコンが止まっても水が出続けない）

最初は水を入れずに LED だけで確かめ、次に 1 台ずつポンプを試す。

## 6. 合わせ直す（シミュレーターを実物に近づける）

組んだら、スマホのスロー撮影と定規で測る：

| 測るもの | どう測る | 直す所 |
| --- | --- | --- |
| 水の高さ | ポンプ 255（全開）・128・64 で、ノズルから先までの高さ | 「ミニ噴き上げ」の高さ（`src/fixtures/water.ts` の `desk-jet`、今 0.1 m）と、`MIN_DUTY`（回り始める所） |
| 上がる速さ | 0 → 255 にしてから、高さの 9 割に着くまで | 物理の立ち上がり（fountain-physics スキル） |
| 落ちる速さ | 255 → 0 にしてから、水面が静かになるまで | 暗転の先取り（今は 3 秒、湖の値） |
| 水の形 | 細い柱か、玉になって崩れるか（表面張力） | 描き方（dev-plan の B7） |

測った数字を Claude に渡して「机の噴水を実物に合わせて」と頼めば、fountain-physics と fit-to-venue の流れで直せる。

## 7. まだ決めていないこと・確かめていないこと

- ポンプ・MOSFET・LED の型番と値段（買う前に、2 の条件で選ぶ）
- 実機での動作（書き込み・Wi-Fi・ポンプ）は確かめていない。確かめたのはコンパイルと、エディタが送る番地の並び（8 台が 1, 6, 11, … 36）
- Wi-Fi が混んでいると Art-Net が遅れることがある。気になったら ESP32 の有線 LAN のボード（M5Stack の LAN モジュールなど）に替える
- 25 台（会場「机の水槽」）にするときは、ピンが足りないので PWM の拡張ボード（PCA9685）を足す
