## 誰が作ったか

- 設計・制作は Walt Disney Imagineering / Creative Entertainment（Steve Davison、技術プロデューサー Chuck Davis）。**WET ではない**（WET の Oarsman / Shooter は Bellagio・Dubai の機材）
- 噴水機材と LED リングは The Fountain People（テキサス州）
- 制御は grandMA2 → EtherCAT（MA Lighting / FTSI）。18,000 以上の制御点

### 首振り機構（Disney 特許 US7886992 / US8459573、2008年、WoC の技術者が発明者）

- 鉛直から全方位 ±55°（110°の弧）。端から端まで2秒未満 → **約55°/s 以上**。位置精度1°未満
- サーボ押し棒2本（120°配置）＋ボールジョイント
- 空気切替でマルチジェット／扇ノズルを選択
- ひねりノズル：外向きの噴口が最大約120rpmで回転し螺旋を描く（ダンサー）
- **LEDリングは噴出口のマニフォールドにあり、ノズルはリングの中心を通る**

## 参考：WET の機材特許（WoC ではない）

- US4978066 Shooter：水中の貯留管を圧縮空気で押し出す。管内流速はノズルの1/36なので**噴出が瞬時に止まる**＝空中を飛ぶ「水の塊」になる
- US5078320 層流ノズル：「ガラス棒のような」滑らかな表面。直下の光ファイバーから**全反射で柱の中を光が通り、柱全体が光る**
- Bellagio：Oarsman 208基・23m・360°回転、スーパーシューター 73m

## 見た目の特徴（レビューと映像からの整理。仕様ではない）

1. **気泡混入した白い水**：WoC の水柱は透明な層流ではなく白濁。気泡が LED の光を散乱し、**柱全体が照明の色で光る**（「どの高さでも色を保つ」）
2. **光は真下から**：各ノズルのリングが自分の水だけを照らす。ラグーンは黒いまま、色は水の中にだけある
3. **場面ごとに単色**：海＝シアン/青、妖精＝緑、炎＝赤橙。フィナーレは色相が配列を走る
4. **霧のハロー**：頂部や縁の分裂・飛沫が柔らかく光る。水面近くの霧がレーザーを受け、反射をぼかす
5. **反射**：暗い水面に色柱のさざ波の縦の筋が映り、見た目の量が倍になる
6. **振り付け**：ウィップの左右・中央から外へのスイープ、グリッドの位相ずれウェーブ、弧・円のチェイス、音のアクセントでのシュート

## 確度

- 確か（Disney プレス・イマジニア発言・特許）：舞台寸法、各機材の数と高さ、首振りの機構
- 弱い：プロジェクター・レーザー台数（検索の断片のみ）、炎の数（ファンサイト経由）、費用、霧の粒径（10〜20µmは一般論）、見た目の評価はすべて主観
