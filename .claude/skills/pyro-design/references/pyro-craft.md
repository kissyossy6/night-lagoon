# 花火の演出の作法

出典の強さ：「実測」はこのプロジェクトで測ったもの、「調べた」は docs/show-knowledge の文献、「一般」は花火の演出で広く言われていること（出典を確かめていない）。

## 1. 採点と構成

- PyroJam 2026 の配点：全体の印象30・構成25・同期15・技術的な設計15・選曲15（調べた、`docs/show-knowledge/k1-director.md` §3）。Cannes・Monaco・Montréal も構成と印象が重い。Monaco は「最後の花束」を別に採点する
- 主な山は終わりから15〜25%の所（調べた）。噴水の主山場（最後の5〜15%）より少し前でもよい。その場合は、最後に花火を足すのではなく、水と光で終わりを作ってもよい
- 花火だけの大会と違い、噴水ショーの花火は**水の上の冠**。花火が主役の時間を短くし、水が主役の時間を邪魔しない

## 2. 段の作り方

- 上がり方は4つ：大きさ（号）・本数・高さ（陸か台か）・広がり（型と spread）。どれか一つを毎回上げる。全部を一度に上げると次の段が残らない（一般）
- 高さの層：台（近い・低い・小さい号）＝前景、陸（遠い・高い・大きい号）＝背景。最初は台だけ、山で陸、最後に両方（このショーの作り）
- 遠さで縮む：客席 [0,7,66] から見た見かけの直径（2026-11-11 の試しの計算）は、台の3号 約14°、台の4号 約23°、陸の5号 約21°、陸の6号 約26°、陸の7号の柳 約15°、陸の10号 約31°。台から陸へ移る所で、号数が上がっても見かけは下がりうる
- 燃える時間も段の一部：大きい号でも燃える秒は同じ（10号の菊も1.8秒）なので、最後の一発が水より先に消えることがある。最後は `burn` を伸ばして、水と一緒に終わらせることを考える
- 比べる相手は直前の一発。水のフィナーレ第2波は、段の中で上がっていたが直前の第1波より暗く、2人の講評者がそろって「下がった」と言った（実測：明るさ 60〜68 → 37〜45）
- 最後の一発は前より大きく。ガイザーを 0.5 に下げた最後の一発は、最初の一発より小さく見えた（講評で指摘）

## 3. 種類の使い分け

| 使いどころ | 種類 | 理由 |
| --- | --- | --- |
| 拍・和音の一打 | 牡丹・菊 | 開いてすぐ消える。次の拍の邪魔をしない |
| 山の直後の溜め・余韻 | 柳 | 長く垂れて、静かな所へ落ちていく。燃える長さを次の場面の頭に合わせて `burn` で切る |
| 細かい連打・ざわめき | 千輪・点滅 | 粒が細かい。多用すると空がうるさい |
| 一度きりの見せ場 | 型物（輪） | 形が読める向きが限られる。何度も使うと驚きが消える |
| 上がっていく線を見せる | 彗星・上がる尾 | 無音や溜めの中を上がる線が、次の一打への期待を作る |
| 低い前景の束 | mine | 一度に12発。低く広く、水の高さに近い |

## 4. 水と花火を合わせる

- **形の韻**：ウィップの扇には扇、交差には X。客は主題の戻りとして読む（このショーで採用）
- **色の韻**：場面の地の色に花火の色を合わせる。多色は時間の方向に1色ずつ（水の「色の記憶」と同じ作り）
- **白の扱い**：白は量を増やすほど壁になる。最後の白は「数本の形」で（10号7本→3本の V字）。水の最後の白も 0.5〜0.85 にとどめる
- **目の行き先を1つに**：花火が開く瞬間は、水を「額縁」（低く・暗く・止める）にするか、水の大技と同じ拍に重ねて1つの絵にする。違う拍にばらばらに出すと、客の目が行ったり来たりする
- **暗転の扱い**：照明の瞬断・押さえの間は、新しい玉を開かない。前の玉の燃え残りが消えきる時間（燃える秒×1.2＋0.2）を引いて、間に合わない玉は早めるか `burn` で縮める

## 5. 同期と音

- 実物のショーでは、開く瞬間は音の立ち上がりの −0.24〜+0.06 秒に入っていた（実測、`docs/show-knowledge/v2-screen-shows.md`）。光を拍に置く
- 本物は打ち上げを上がる時間の分だけ先に点火する（1.75インチで約2秒、6インチで約5.2秒、調べた）。このプロジェクトでは `t` を開く時刻として書けば、打ち上げは自動で先になる
- ドンは距離の分だけ遅れる（客席で0.6〜1.3秒）。本物と同じなので、そのままでよい。ただし、ドンが無音・照明の瞬断・最後の和音の後の静けさに落ちる位置は確かめる
- ユーザーは「迫力は音で」と考えている（花火の音は大きく、音楽で下げない）。ドンの中身を変えるのは sound-design

## 6. このプロジェクトで実際に起きた失敗

| 起きたこと | 直し方 |
| --- | --- |
| 10号7本をまっすぐ打ったら、重なって白い壁になり、上が画面から切れた | 3本を V字に開いた。席を少し上へ向けた |
| 客席のカメラ（目の高さ7 m）では花火が画面の外で、確かめられなかった | 席「花火と水」（`cam=sky`）を足した |
| 柳（5.75秒）が次の場面の頭（178.54）まで垂れ残った | `burn: 3.8` にして 178.55 に消えるようにした |
| 最初のドンが 35〜60 Hz の正弦波で、ノートパソコンでは鳴らず「ちゃっちい」と言われた | 実物の録音を測って作り直した（sound-design） |
| 花火のシェーダーを足しただけで、花火の無い版の絵が数画素ずれた | 花火のある版だけに入るよう `#ifdef` で囲み、他の版は0画素の差を確かめた |
| 10号も菊の燃える秒（1.8秒）のままで、最後に一度に消える | 気づいているが直していない（号数で燃える秒を変えるかは未定） |
