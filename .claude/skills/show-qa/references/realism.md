# 本物らしさの表

このプロジェクトで、ユーザー（現実の噴水を見てきた人）や講評者が「現実と違う」と指摘したことと、その後の決まり。数値はコードが正しい（食い違ったらコードを読んでここを直す）。

## 目次
1. 光（LED）
2. 水の出し入れ
3. 消えていく水・霧
4. 水幕と映像
5. 白と明るさ
6. 段取りが見えること
7. 音

## 1. 光（LED）

| 見えてはいけないこと | 本物では | このプロジェクトの決まり |
| --- | --- | --- |
| 柱全体の色が一度に変わる | 色はノズルから先へ、一瞬で上がっていく | 水がたどった道のりの分だけ遅らせる（45 m/s、最大1秒、`jetfield.ts` の shade）。90 m/s は高い弧には速すぎた |
| 先まで同じ濃さの色 | 先へ行くほど薄い。垂れ下がる所が一番薄い | ウィップと扇は道のり30 m で exp で薄く（`fadeLen`） |
| パッと色が変わる・パッと暗転 | LED にも立ち上がりがあり、ショーでは見せ方として急に変えない | 色0.6秒・明るさ0.9秒・点く0.12秒が下限（`cues.ts` が強制）。2:49 の赤→青はそれでも急と言われた。場面の区切りは1〜2秒かける |
| ショーの途中で真っ暗 | 途中で全部消すことはまずない | 2:54 の全暗は「現実にない」と言われ、0.3〜0.5 の減光にした。0.3秒の瞬断で 30% まで落としたら「下げすぎ」、65% にした |
| 泡やしぶきに色がしっかり乗る | 泡は白っぽい。しぶきの色は薄い | 着水のしぶきの色 40%・明るさ ×0.8、遠くは 8% |
| リアルモードで細い柱の根元が白く飛ぶ | 小さいノズルでも色は残る | ソフトクリップで直した。リアルと理想の両方で撮る |

## 2. 水の出し入れ

| 見えてはいけないこと | 本物では | 決まり |
| --- | --- | --- |
| 花・扇がゆっくり大きくなる（拡大縮小に見える） | 弁で開け閉めする。スパッと出てスパッと止まる | 開0.2秒・閉0.25秒（`VALVE_OPEN_S`・`VALVE_CLOSE_S`） |
| 暗い中で形ができていて、拍で光だけが入る | 水は音楽と一緒に伸びていくほうが、このユーザーには自然 | 1:32 の入りは「いきなり出現して不自然」と言われ、ピックアップの拍から中央から伸ばすように直した |
| 首振りが速すぎる | 首振りには速さの上限がある | 90°/秒（`HEAD_MAX_DEG_S`）。上限にかかったキューは make-proposal が数を出す |
| 柱の先が平たい板・麺のように見える | 先は崩れて散る | 共通の `headOf()` で先を消し、散らす（ウィップの「バレエのヒモ」「麺」と言われた） |

## 3. 消えていく水・霧

| 見えてはいけないこと | 本物では | 決まり |
| --- | --- | --- |
| 照らされていない落ちる水が、黒や灰色の筋に見える | 暗い水はほぼ見えない | 粒・帯・霧は、照らされた割合だけ後ろを隠す（下限15%）。2回起きた（ラボ 10-23、ショー 10-26） |
| 暗転のはずなのに、落ちる途中の水が光っている | 水が落ちきるまで約3秒（湖の大きさ） | 暗くしたい時刻の約3秒前に消し始める。光は弁と一緒に落とす |
| 大技の霧が次の絵に残る | ガイザーの霧は10秒以上残る | 終わりの絵から逆算する（fountain-physics）。全高のガイザー10本は霧で 175〜176 秒を白くした |
| 待機中のリングやチェイサーが暗転の中で光っている | 使っていない機材は消えている | 0 にして光も消す（idle の輪が太陽の前に出た） |

## 4. 水幕と映像

| 見えてはいけないこと | 本物では | 決まり |
| --- | --- | --- |
| 映像が幕と一緒に縮む・明るすぎて霧の外へはみ出る | 後ろから投影する。霧が濃い所だけはっきり映り、枠は空間に止まっている | 背面投影として描く（`projection.ts`） |
| 幕を下げたのに、残った霧に映像が映り続ける（2:39 の幽霊の幕） | プロジェクターは霧と別の機材 | 映像の明るさはプロジェクターのキューで決める。下げた後の霧に映さない（警告が出る） |
| 物語が客席から読めない | 幕は画面の高さの1〜2割 | 大きな形・黒地・ゆっくり（water-screen-media）。未解決 |

## 5. 白と明るさ

| 見えてはいけないこと | 決まり |
| --- | --- |
| 全部白・全開で、霧の白い壁になる（明るさ 124〜132） | 白は 0.5〜0.85、床は低く、数本の形に。最後の和音は「色の少ない大量の水」でも、形が読めるように |
| 主役が床と同じ色で消える | 主役は差し色か、0.4〜0.5 明るく |
| 段の中で上がっていても、直前の山より暗い | 直前の区間と明るさを比べる（`sheet.py bright`） |

## 6. 段取りが見えること

首振りの戻り、水が落ちる途中、待ち時間、待機の輪、点いたままの残りの水。客に機材のことを考えさせない（Davison）。暗転と谷の前後を連続コマで見る。

## 7. 音

- 自分で作った音楽・音は何度も断られた（ラプソディーの編曲「全然ダメ」、35〜60 Hz の正弦波のドン「ちゃっちい」、水しぶき「しゃーって感じ」）。音は実物の録音を測って作る（sound-design）。曲は作らない
- 自動の再生や試しで音を出さない（「音聞こえないようにして」）
