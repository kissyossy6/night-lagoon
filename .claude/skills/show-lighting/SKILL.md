# show-lighting（照明と色）

噴水の色は「水の中にだけある」。ラグーンも空も黒く、リングが照らした水だけが見える。だから照明は、色を塗るだけでなく **何を見せて何を消すか** を決める仕事でもある。照らさない水は客には存在しない。

このプロジェクトの書き方は `.claude/skills/show-director/references/project-api.md`。原則の出典と、場面の性格ごとの色の例は `references/color.md`。

## 進め方

### 1. カラースクリプトを先に作る

ピクサーの Ralph Eggleston は、全場面の色を黒い紙の帯に小さく並べてから映画を作った。噴水ショーでも、振付の前に色を1本の帯にする。曲の区切り（show-director の構成表）ごとに：

| 区間 | 感情 | 地の色 | 差し色 | 明るさ（0〜5） | 切り替え方 |
| --- | --- | --- | --- | --- | --- |

並べてから、次を見る：
- **流れ**：彩度は感情の強さについていく。静かな所はくすませ、高まるほど鮮やかに（Toy Story、WALL-E）
- **対比**：暖色は寒色の後に来ると強く感じる。色は前の場面との差で効く
- **終わりは始まりの色に戻す**（WALL-E）。ショーが一周して帰ってきた感じになる
- **白は数本の柱だけ**：最後の一撃で白い柱を増やすほど、照らされた霧で空ごと白くなり、形が消える（このショーでは、ガイザー10本とウィップ24本を白にしたら画面の明るさが他の山の2倍になった）。白は一番高い柱だけにし、他は差し色で支える。中央を空けると、奥の絵（日の出）が見える窓になる
- **全部の色は1回だけ**：多色（rainbow）・全部白は山場のご褒美。ユーザーの好みも「1場面1色＋差し色1色、多色はたまに」
- **多色は時間方向に出す**：World of Color 2010 と万博「アオ」のフィナーレは、どちらも全面を2秒ごとに単色で切り替える作りだった（実測）。3色以上を同時に出していた時間は全体の8〜12%。同時の虹（`rainbow`）は、使うなら一か所の「絵」として短く

### 2. 場面の中の光：何を見せるか

舞台照明の McCandless は照明の機能を「見える・形・場所・雰囲気」とし、変えられるのは「強さ・色・分布・動き」の4つとした。Pilbrow は「見せたいものだけを見せる」と言った。噴水に移すと：
- **焦点**：一番明るい所に目が行く。主役の群を一番明るく、脇役は intensity を下げる（0.5〜0.7）。中央を明るく端を暗くすると絵がまとまる
- **主役を床の色に溶かさない**：ウィップは細い線なので、床（グリッド）と同じ色だと客席からはほとんど見えない。このショーでは2回起きた（第2トゥッティの紫のウィップ、第1トゥッティのピンクのウィップ）。主役は差し色にする（第2トゥッティは金にした）か、同じ色なら intensity を床より0.4〜0.5上げて床の高さの上限を一段下げる（第1トゥッティはウィップ 1.35、床 0.85）
- **形**：泡の柱は真下からの光で輪郭が出る。リングは真下にある（機材どおり）
- **暗さの価値**：明るさは比べて感じる。真っ暗の後のロウソク1本は、明るい舞台を落としたロウソク1本より明るく見える。山の前に暗さを作る

### 3. 光で拍を打ち、水でフレーズを描く

LED は水より速く変わるが（色0.6秒・明るさ0.9秒・点く0.12秒が下限。`src/show/cues.ts` が強制する）、水は上がるのに1秒以上かかる（fountain-physics）。分担する：
- 拍・打撃・アクセント → **光**（intensity のパルス、色のバンプ）。先取りなし
- フレーズの起伏 → **水**（高さ・隊形）
- 色の切り替え方：場面の区切り（4〜8小節）はクロスフェード（1〜2秒）、出来事は速く（下限の0.6秒。光はノズルから先へ上がっていくので、柱全体が一度に変わるスイッチには見えない）、チェイスはアクセントの後の波で。下限より速くしようとしない：ユーザーは本物の噴水を知っていて、0.6秒にした後も 2:49 の赤→青を「急」と言った
- キューは拍ごとではなく、曲の区切りごとに置く。毎拍で色を変えると目が疲れる（コンサート照明の作法）

**白の使い方は2流儀ある。** World of Color は色が場面を作る（1場面1色＋差し色）。Bellagio はほぼ白一色（色付きは2〜3%）、Dubai は山場で白・色は前奏や静かな節だけで、**白が「全開」、色が「待ち・静けさ」の合図**になっている（実測）。このショーは WoC 流が基本だが、入りの一撃で「色→白」に替える手は両方で効く。

**照明だけの瞬断。** Bellagio は休符で照明だけを落とし（水は出たまま）、拍の上で戻す。最後の一撃の前に照明を0.5秒落とす。暗転より軽い区切りとして使える。**ただし0まで落とさない**：このショーで 0.3秒の瞬断を30%まで下げたら「明るさ下げすぎ、不自然」と言われて65%にした。2:54 の全暗も「現実にない」と言われ 0.3〜0.5 の減光にした。ショーの途中は、浅く始めて足りなければ深くする

### 4. 目の性質に合わせる

- **夜の目には青緑が明るく、赤が暗く見える**（プルキンエ現象）。青・シアンの場面は弱めでも見える。赤・赤橙の場面は intensity を1段上げないと沈む
- **泡の水には透明な水の約2倍の光が要る**（Crystal Fountains 社長）。泡の多いガイザー・フラワーは明るめに
- **RGB で作る白は青や緑に寄る**。`real` で本物らしさを出すなら、白を純白ではなくわずかに寒色に（推測）
- **点滅は1秒に3回まで**（WCAG）。特に彩度の高い赤の点滅と、水幕のように視野を大きく占める面の点滅は避ける

### 5. 空気の色

もや（`src/show/haze.ts`）とガイザーの霧は、照らすと光の柱や空の色になる。狙ったときだけ照らし、他は落とす。ガイザーを打った後はリングを落とさないと、霧が後の場面に光る柱として残る（今の振付は対処済み）。チェイサーも同じで、撃った後に点けたままだと霧が光り、白で撃つと場面の色の真ん中が灰白色に濁る。チェイサーの色は場面の差し色にし、白は山場だけにする。

## 場面の性格 → 色の組み立て（目安）

| 性格 | 地 | 差し色・明るさ |
| --- | --- | --- |
| 静か・導入 | 青〜シアン、彩度・明るさ低め | 差し色なし、暗さを残す |
| 神秘・夜 | 深い青 | 小さな緑か白を大事な所だけに |
| 目覚め・期待 | くすんだ寒色から | 彩度を少しずつ上げる |
| 祝祭・高揚 | 金・橙・赤橙、明るく（赤は強めに） | 補色の青を少しだけ |
| 緊張 | 暗い、赤 | 補色をぶつける |
| 郷愁・希望 | 夜明けの青 | 暖かい一点 |
| クライマックス | 全色、または全部白 | 一度だけ。直前に暗転か静止 |
| 余韻・終わり | 冒頭の色 | 消えていく |

色と感情の対応は30か国の調査で大部分が共通（r=.88）だが、国による差もある。暖色＝活気、寒色＝静けさのような広く共通する対応に頼り、白＝弔い・赤＝祝いのように文化で分かれる意味には頼らない。

## チェックリスト（レビューで使う）

- [ ] カラースクリプトがあり、場面ごとに地の色1つ＋差し色1つになっている
- [ ] 多色・全部白は1〜2回だけで、直前に暗さか静けさがある
- [ ] 彩度と明るさの流れが、曲の強弱の流れと合っている
- [ ] 終わりの色が始まりの色に戻っている（戻さないなら理由がある）
- [ ] 各場面で一番明るいのが主役の群になっている
- [ ] 赤系の場面の intensity が、青系の場面より1段高い
- [ ] 色の切り替えが区切りに乗っていて、毎拍で変わっていない
- [ ] 点滅が1秒に3回を超えない
- [ ] 暗転のとき、水を止めるのが先、光を落とすのが暗転の時刻（fountain-physics）
- [ ] `real` と `ideal` の両方で成り立つ。`real` に光を足していない

## 出すもの

カラースクリプトの表と、キューにしたときの `set(t, target, { color, intensity }, dur)` の案。直すときは「何秒の、どの群の、何を、なぜ」を1行ずつ。

## このスキルがしないこと

水の動きや隊形は決めない（fountain-choreography）。水幕の映像の中身は water-screen-media。ただし水幕の近くの噴水の明るさは、映像のコントラストを守るためにこちらで落とす。
