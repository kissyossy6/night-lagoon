## 照明

| # | 原則 | 根拠・確度 |
| --- | --- | --- |
| L1 | 光は水の中・真下から。空からの投光は大半が噴流の横を通り過ぎる | 特許 EP2116760B1・高 |
| L2 | 泡立った水には、同じ高さの透明な水の約2倍の光が要る | Crystal Fountains（WaterShapes）・高 |
| L3 | レンズは水面下 2.5〜5cm、泡ノズルから60cm 以上離す | 同上・高 |
| L4 | 1つの効果に2台以上、輪の内側から | 同上・高 |
| L5 | 噴水ごとに自分の光源を。隣どうしで色をつなげ、濃淡をつけられる。WoC は約2年かけて専用の LED を作った | Wikipedia・中 |
| L6 | RGB の白は青や緑に寄る。RGBW のほうが白とパステルがきれい | 業者・中 |
| L7 | 濃い色・彩度の高い色は同じ見え方のために強さが要る | ETC・中 |
| L8 | 夜の目は青緑が明るく赤が暗い（感度の山が 555→507nm へ） | 視覚の基礎・高 |
| L9 | 明るさは比べて感じる。暗さが次の明るさを作る | 照明の教科書・中 |
| L10 | パッと変えるのは出来事、ゆっくりは時間の流れ。速い変化が多すぎると疲れる | ETC・中 |
| L11 | キューは拍でなく区切りに。全機材の絵は山場まで取っておく（200台なら50台で土台）。ドロップの直前に一瞬の暗転か静止、山の後は暗く簡素に | コンサート照明の業界ブログ・中 |
| L12 | 点滅は1秒に3回まで。彩度の高い赤の点滅は特に避ける | WCAG 2.2・高 |

## 色

| # | 原則 | 根拠・確度 |
| --- | --- | --- |
| C1 | 全体の色を1本の帯に並べて決める（カラースクリプト） | Eggleston・高 |
| C2 | 彩度は感情の強さについていく | WALL-E、Toy Story・高 |
| C3 | 意味を持たせた色は大事な瞬間にだけ出す（「1場面1色＋差し色」の根拠） | Eggleston・高 |
| C4 | 場所・場面ごとに色の個性を決める | 同上・高 |
| C5 | 色は前の場面との対比で効く。全部の色は数回だけ | Block・中 |
| C6 | 終わりは始まりの色に戻す | WALL-E・高 |
| C7 | 色と感情の結びつきは大部分が世界共通（30か国、r=.88）だが国による差もある | Psychological Science 2020・高 |

| C9 | 白は品のよい抑えの色（Bellagio は全部白） | Wikipedia・中 |
| C10 | 暖色は明るく、寒色は沈んで感じる | ETC・中 |

## レーザーと霧

- ビームは粒子がなければ見えない。ヘイズは均一で光の面がなめらか、濃い霧はうねる（ILDA・高）
- 緑のレーザーが一番明るく見える（目の感度・中）
- 空気に色を乗せるには、ガイザーの残り霧や水幕の霧を照らす。狙った時だけ照らし、他は落とす（推測）

## 噴水への当てはめ（今のショーで気づいたこと）

- 赤・赤橙のフィナーレ（手前 0.7）は同じ数値の青より暗く見える。赤の帯は1段強く（L8）
- 白はガイザーとクライマックスにだけ。中間の場面で白を差し色に使いすぎない（C9・L11）
- 物語の前の暗転は L9・L11 に合う。フィナーレの前にも短い暗転か静止を置く価値がある
- `real` の泡の柱は、根元が明るく上へ行くほど暗くなるのが本物どおり（L2・推測）
