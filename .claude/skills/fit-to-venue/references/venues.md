## 1. 会場の決まり方

- ショーのファイルの `venue`（無ければ湖）。プレイヤーは `?venue=<id>` で上書きでき、そのときカメラの席はその会場のものになる
- エディタの「会場：〇〇 ▾」（`src/editor/main.ts` の `switchVenue`）で `venue` を書き換える。⌘Z で戻せる。切り替えると「動かないキュー N・一部だけ M」と出る。会場に無いグループのキューは灰色の行「この会場に無い」へ
- 会場の読み方：組み込み（`src/venues/builtin/*.json`、置けば増える）→ venue.html で作ったもの（localStorage `water-show-venues:v1`）→ 無ければ湖
- 部品の名前がそのまま `@名前` の並びになる（部品がグループ全体なら `@名前 = group`）

## 4. 会場の決まり（`src/venues/rules.ts`）

- 止める：build・outside・ground・overlap（同じ種類が間隔より近い）・samespot（違う種類が小さい方の間隔の0.1倍より近い）
- 赤：pyroSafety・spray（2h·sin2θ＋0.2h が客席に届く）・burst
- 黄：close（間隔の0.4倍より近い）・spill（縁までの距離が足りない）・pump・heavy・noSeats・projector
- ポンプの上限 L/s：机 0.3・庭 5・広場 150・湖 5000
- 組み込みの小さい3会場は警告0、湖は 止める0・赤1・黄2
- 赤と黄は、わざと破ってもよい（dev-plan §1.F：置けない／赤／黄の3段）

## 5. 動かないキューの数え方（`src/venues/cues.ts` の `cueReach`）

- キューの的を、ショーの会場と行き先の会場で数える。行き先で0＝動かない、少ない＝一部だけ
- 理由：名前の付いた並びが無い／書き方が読めない／グループが無い・花火の台が無い／番号が範囲の外
- 範囲は切り詰められる：18台の机で `grid[0-87]` は18台全部（一部だけ）、`grid[88-175]` は0
- 組み込みの振付は番号で書いている（`choreography.ts` の `ROW = { front:'grid[0-87]', mid:'grid[88-175]', back:'grid[176-263]' }`）。これが動かないキューの元
- 2026-11-11 の数（Night Lagoon、469 キュー）：広場 動かない265・一部199、机 動かない319・一部150
- 音楽の解析で生まれるキューがあるので、音楽ありとなしでキューの数が違う（reach.mjs は音楽ありで数える）

## 6. 規模で縮むもの・縮まないもの

| 縮む（自動） | 縮まない（湖のまま） |
| --- | --- |
| 粒の飛ぶ時間（高さから重力と空気で計算、`flightTime`） | 水の風 `uWind (0.6,0,0)`（会場の風は花火と煙だけに効く） |
| 粒・霧・波紋の大きさ（`drawScale`：高さ10 m より下は高さに比例） | 首振り 90°/秒、弁 開0.2・閉0.25秒 |
| | LED の変化の下限 色0.6・明るさ0.9・点く0.12秒 |
| | ポンプの立ち上がり 1秒、水が届く時間の見積もり |
| | 「暗転は約3秒前に消し始める」（キューを書く人の決まり） |
| | 表面張力・しぶきの粒の大きさ（本物の机の水は粒が大きく、霧にならない） |
