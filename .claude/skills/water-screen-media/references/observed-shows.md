# 実際のショーで観察した水幕の型

客席からの映像を2秒ごと（要所は0.5秒ごと）に見て、10fps の明るさと音の立ち上がりで時間差を測った。時刻は動画の時刻。原本は `docs/show-knowledge/v2-screen-shows.md`、代表コマは `shots/show-analysis/v2/`。

## 対象

| ショー | 映像 | 水幕 |
| --- | --- | --- |
| Wings of Time（シンガポール・セントーサ） | 全編、客席中央の後ろ寄りから三脚で固定 | 横長の彫刻（マッピング面）の後ろ中央に半円のドーム水幕。左右の扇の水膜、高い柱にも映す |
| ビリーヴ！～シー・オブ・ドリームス～（東京ディズニーシー） | 9:50–24:50、手持ちで時々ズーム | 台船ごとの小さな矩形の幕が複数。霧が均一 |

## 数値

| | Wings of Time | ビリーヴ！ |
| --- | --- | --- |
| 場面 | 19、平均約60秒 | 17、平均約53秒 |
| 水幕（人物の映像） | ドーム約32%（1回11〜100秒、中央値26秒） | 人物約18%、幕に何かを映す時間は約70% |
| 映像なしで噴水が主役 | 約13% | 約22% |
| 暗転 | 1〜2秒が約10回、長いのは8秒が2回 | 約12秒が1回、短い暗が数回、34秒の暗い場面 |
| 区切りと音のずれ | 0.1秒以内 | 0〜0.2秒（光がやや先） |

## 型

| 型 | 例 | このショーでの作り方 |
| --- | --- | --- |
| 出すときは主役、噴水は休むか額縁 | WoT 7:00 会話（暗い地に小さな人物、他は消す）、12:00 | 水幕の間は whip の額縁以外を消す |
| 人物は小さく、霧の厚い下半分 | WoT 7:00（幅の約1/3） | 舟・人物は山の幅の1/3以下、下半分 |
| 幕全体は大きく単純な形だけ | WoT 11:36 青一色、14:32 太陽、20:06 赤一色 | 物語の始まりや終わりに山を単色で塗る |
| 周りの色替えが先、霧と映像は約2秒後 | WoT 2:53 彫刻の色→2:55.5 霧→2:57 ドームが揃う | 水幕を上げる2秒前から額縁や grid の色を替える |
| 単色に塗ってから霧を下ろす | WoT 4:06–4:18 | 消す前に `projection.ts` で幕を単色に |
| 人物は爆発や泡に変えてから消す | WoT 7:22 桃色の爆発、ビリーヴ 13:26 泡 | 舟が光の粒になって消える、など |
| 映像から実物へ（1.0秒後、同じ位置） | WoT 10:23 映像の鳥が中央で光る→10:24 実物の火球 | 映像で光った x に約1秒後の geyser か chaser |
| 映像を幕の外の水へ続ける | WoT 3:20 鳥の翼が彫刻へ、8:50 柱、9:10 扇 | 映像と同じ色で額縁や grid を光らせる（推測） |
| 3面を同時に使うのは頂点だけ | WoT 10:14–10:25 ドーム＋左右の扇 | 3つの山に別々の絵は1回だけ |
| 複数の幕はふつう同じ質感 | ビリーヴ 14:26、14:50 | 3つの山に同じ色・ゆらぎ |
| 額縁：左右から内へ倒したアーチ | WoT 11:42–12:10 | `whip[3-6]`・`whip[17-20]` を内へ（今の物語の場面と同じ） |
| 額縁：左右の端だけに色の柱 | WoT 6:26、19:08 | 端の whip を垂直に、場面の色で |
| 額縁：幕の下を低い噴水で縁取る | ビリーヴ 13:04 | 水幕の前の grid の前帯を低く一列に |
| 山場では映像を捨てる | WoT 13:50・20:22 噴水だけの白、ビリーヴ 21:42 幕を青一色 | フィナーレは山を単色に塗るか下ろす |
| 区切り：一撃で締める→暗い間→次の場面の一番小さい要素 | ビリーヴ 13:25.5 花火→13:27 幕が泡→13:28 目だけ | ガイザーの短い一発か白い閃光→暗→小さな点から |
| 悪役・山場の前は最小の要素から | ビリーヴ 13:28 暗い幕に目だけ、19:32 暗い中の小さな人物 | 物語の始まりは月か舟の一点から |
| 色替えは同じ絵の色だけ替える | WoT 15:56 夕焼けの風景をそのまま青い夜に | 時間の経過を色だけで |

## World of Color との違い

- Wings of Time は固い映写面（彫刻）にも常に映すので、水幕を下ろしても絵が残る。WoC とこのシミュレーターには固い面がないので、水幕を消した場面は grid と照明の色で場面を保つ
- 大技：WoT は炎を1場面にまとめ、一番高い柱はフィナーレだけ。ビリーヴ！は花火を区切りとして1〜2分に1回。花火のないこのショーでは、区切りの一撃はガイザーの短い一発か白い閃光で代える（推測）
