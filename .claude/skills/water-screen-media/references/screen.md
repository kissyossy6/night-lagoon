## 原則

| # | 原則 | 根拠・確度 |
| --- | --- | --- |
| S1 | 背面投影。前面投影は周りに光が一切ない条件だけ。前面だと幕の後ろの物にも像が二重に映る | Aquatique・高 |
| S2 | ホットスポットは消えない。見える角度も狭い（水滴が大きいほど光は前へ散る） | 特許・中〜高 |
| S3 | 霧はにじむ。大きく、ゆっくり、くっきりした形で。飾り線は消える | 業者の解説・中 |
| S4 | 黒い地に鮮やかな色を高コントラストで | 業者 FAQ・中 |
| S5 | 大事なものは縁に置かない（縁は不規則でゆらぐ） | 同上・中 |
| S6 | 明るさは像の面積に反比例（半分の大きさで約4倍明るい） | GoboSource・中 |
| S7 | 周りの光が像を消す。水幕の近くの噴水を明るくし続けない | 業者・中、噴水への当てはめは推測 |
| S8 | 大きな水幕には2万ルーメン級のプロジェクターを固定で（WoC 12台、Bellagio 16台） | 中〜高 |
| S9 | キャラクターは何枚かの水幕に分けて映す | WoC（Kebour）・中 |
| S10 | 映像は実物の水で早くから試す（Ocean Park の Symbio では試験が作風を決めた） | Blooloop・中 |
| S11 | 水幕は要素の一つ。万博「アオ」は中央 18〜20m のカスケード幕と左右2枚に、噴水約300基・水中 LED 308台・炎36基を組み合わせた | 高（WoC）・中（万博） |
| S12 | 幕は投影のある時だけ出す | 特許 US8328367・中 |

## 今の映像（`projection.ts`）で気づいたこと（2026-10-26 調査時点）

- フィナーレで虹色を全面に塗り（不透明度 0.2〜0.4、毎拍で色がずれる）、ビルドの終わりに全面白 85% のホワイトアウト、フィナーレの頭に全面フラッシュがある。S4・S6 と「多色はたまに」の方針に反する。黒地に虹のアーチと弾ける光だけ、全面の白は1回だけ、が案
- 毎拍のパルスは 120BPM で毎秒2回なので点滅の上限内。8分音符で光らせると毎秒4回で超える
- lineWidth 2〜3px（15〜23cm）の線は霧で消える
- 舟と月は話の主役。大きなシルエットとして中央寄りに。蛍・星・灯籠は飾り
- 山の水幕は縁が下がる形なので、主役は各山の中央の高い所に
- 背面・固定プロジェクターの今の作りは WoC と同じで正しい
