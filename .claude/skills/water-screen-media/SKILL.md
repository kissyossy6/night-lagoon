# water-screen-media（水幕の映像）

水幕は「映画のスクリーン」ではない。霧は光をにじませ、縁はゆらぎ、背面から投影するので中心が明るく横から見ると暗い。そのうえ周りでは噴水が光っている。この条件で読める絵だけを映し、水幕を「何もなかった所に像が現れる」魔法として使う（ECA2 の Yves Pépin）。World of Color でも主役は水で、水幕は要素の一つ（Steve Davison）。

このプロジェクトの水幕のキュー（`screen`、`mound`、`clip`）は `.claude/skills/show-director/references/project-api.md`。映像は `src/screen/projection.ts` で手続き的に描く。原則の出典は `references/screen.md`。実際のショーで観察した型は `references/observed-shows.md`。

## 1. いつ出すか

水幕は強い道具なので、出しっぱなしにしない。
- 出すのは「物語」「顔・キャラクター」「水では描けない具体的な絵」が要る場面だけ。抽象の高揚は水と光で足りる
- **出すときは主役**。水幕が出ている間、噴水は消すか額縁だけにする（Wings of Time・ビリーヴ！の実測）
- 実測の割合：Wings of Time はドームの水幕が本編の約32%（1回11〜100秒、中央値26秒）、ビリーヴ！は人物の映像が約18%（残りは幕に色や質感を塗るだけ）。3分のショーなら合計50〜70秒、2〜3回、1回15〜40秒が目安
- **山場では映像を捨てる**。Wings of Time の山場は噴水だけの白、ビリーヴ！は幕を青一色に。山場に人物は出さない
- 出ていない間は投影を黒にし、霧が上がってから像を入れる。霧が無い所に映すと、像が客席側の物に当たる

## 2. 形を選ぶ

| 形 | 向く内容 |
| --- | --- |
| 横長の1枚（`screen`） | 横へ渡る動き（舟が端から端へ）、パノラマの風景、全景の山場 |
| 中央の山（`mound[1-1]`） | 主役1人・1つの物の登場、物語の始まり |
| 左右の山（`mound[0-0]`・`mound[2-2]`） | 脇役、掛け合い、場面転換、中央への視線の誘導 |
| 3つの山 | ふつうは3つに同じ質感（色・ゆらぎ）を映す。3つに別々の絵を同時に出すのは場面の頂点だけ（Wings of Time はドーム＋左右の扇を頂点で1回） |

形は映像の中身で決める。中身が横に動くなら横長、1つの物が主役なら中央の山。

**主役の大きさと位置**：形の崩れる霧の幕（ドーム・山）では、人物や舟は幅の1/4〜1/3で、霧の厚い下半分に置く。幕全体を使うのは、太陽・単色の塗り・爆発のような大きく単純な形だけ（Wings of Time）。霧が均一な小さい幕なら幕いっぱいでよい（ビリーヴ！）。

## 3. 霧の上で読める絵

作ってよい：
- **黒い地**に像を浮かべる。黒は光が無いので、水幕そのものが消えて像だけが浮く
- **大きなシルエット・太い形・ゆっくりした動き**。霧は細部をにじませる
- 線は太く：キャンバス 1536px が 116m なので 1px ≈ 7.5cm。2〜3px の線は霧で消える。物語に要る線は 7〜13px（0.5〜1m）以上（推測）
- 大事なものは**中央付近**に。縁と山の肩はゆらいで暗い
- 1画面1色＋差し色。噴水の色と同じ系統にすると、場面が一つにまとまる
- 小さな点（星・蛍）は、なくても話が通じる飾りにだけ

作ってはいけない：
- 細い線・小さい文字・細かい模様
- 灰色の上に灰色のような弱いコントラスト
- 画面全体を明るい色で長く塗りつぶす（像の面積が大きいほど1点あたりは暗い。噴水も霧も見えなくなる）
- 1秒に4回以上の全面フラッシュ、赤の点滅（視野を大きく占めるので危険）
- 速いパン・細かい揺れ（霧のにじみで流れる）

## 4. 噴水・照明とのつなぎ

- **額縁**：物語の間は、水幕の両脇を whip のアーチなどで囲み、他の機材は消すか最小限（WoC の観察、合意済み）
- **額縁の明るさを抑える**：水幕の近くの噴水が明るいと映像のコントラストが落ちる。映像が明るい間は額縁を下げるか、映像の地と同じ系統の色に
- **映像から実物へ**：Wings of Time では、映像の中の鳥が中央で白く光り、**1.0秒後に同じ位置で実物の火球**が上がる。このショーなら、映像の中で光った x に約1秒後のガイザーか chaser。1つのショーで1回でよい
- **映像を幕の外へ続ける**：Wings of Time は同じ映像を扇や柱の水にも当て、映像が幕より大きく見えるようにしている。このショーでは、映像の色と同じ色で額縁の whip や手前の grid を光らせると近い効果になる（推測）
- **出し方**：周りの色替えが先、霧と映像は約2秒後（Wings of Time）。霧を立て始めてから映像が読めるまで約2秒かかるので、その間に周りの色で「場面が始まった」と見せる
- **消し方**：幕全体を単色に塗ってから霧を下ろす。人物は爆発や泡に変えてから消す。像を先に落とし、霧は後
- **区切りの型**：一撃で締める → 暗い間 → 次の場面の一番小さい要素から（ビリーヴ！：花火と噴水で締め → 暗い幕に悪役の目だけ）
- **暗転**：音の休符に合わせて1〜2秒が基本。大きな区切りだけ8〜12秒。区切りは音と0.1〜0.2秒以内
- **カメラ**：物語の場面ではカメラを自動で寄せない（合意済み）

## 5. 確かめる

- `node scripts/projection-check.mjs` で映像のコンタクトシート
- `node scripts/show-shot.mjs --t=<秒>` で客席からの見え方（霧の濃さ・額縁・噴水の明るさ込み）。映像だけで良く見えても、霧と噴水の中で読めるとは限らない
- 横から（`?cam=left`・`?cam=right`）も見る。背面投影は横から暗い

## チェックリスト

- [ ] 水幕を出す理由（物語・具体的な絵）がある。合計は全体の3〜4割まで
- [ ] 形（横長・山）が中身の動きに合っている
- [ ] 地は黒、主役は幅の1/4〜1/3で霧の厚い所（中央・下半分）、線は 7px 以上
- [ ] 山場では人物を出さず、映像を捨てるか単色に塗るだけ
- [ ] 周りの色替えが先、霧と映像が約2秒後。消すときは単色にしてから下ろす
- [ ] 全面の色・全面の白は山場の一度だけ
- [ ] 点滅が1秒に3回以下
- [ ] 物語の間、周りの噴水は額縁と最小限で、映像より明るくない
- [ ] 霧が満ちてから像が入り、像が先に消える
- [ ] 客席からの撮影で読めることを確かめた

## 出すもの

場面ごとに「形・中身・色・噴水の役・出入りの時刻」を表にし、`projection.ts` の描き方と `screen`／`mound` のキューの案を添える。
