# 講評の採点表（100点）

花火の音楽演出の採点（PyroJam 2026 の公式配点：全体の印象30・構成25・同期15・技術設計15・サウンドトラック15、カンヌ・モナコの審査項目）を噴水に置き換えた。サウンドトラック（選曲）は既存の録音で固定なので、その15点を「色と光」に回した。

点数は目安。大事なのは各項目で「時刻・何が・どう直すか」を言えること。

## 1. 全体の印象（30）

| 観点 | 満点の状態 |
| --- | --- |
| 感情 | 一文のコンセプトがあり、見終わってその感情が残る |
| 役者としての水 | 機材の一覧ではなく、主役の群に性格と役がある |
| 楽に見える | 首振りの戻り・水の落ちる途中・待ち時間が見えない。段取りが見えない |
| 記憶に残る瞬間 | 「あれが良かった」と言える瞬間が1〜2つある |
| 品位 | 安っぽい効果（全面の点滅、意味のない虹）がない |

## 2. 構成（25）

| 観点 | 満点の状態 |
| --- | --- |
| 始まり | 静かな一点で目を奪う（曲が爆発で始まる場合を除く） |
| 山と谷 | 第一の山 → 谷 → 主山場。強い区間が30秒以上同じ見た目で続かない |
| 山の位置 | 第一の山が全体の55〜80%、主山場が最後の5〜15%。山の前は密度2〜3で溜め、山の後に谷 |
| 手札 | 山ごとに初めて出すものがある。前半で手札を出し切っていない |
| ご褒美の配り方 | ガイザー3回前後、多色は全体の1割まで（できれば時間方向の切り替えで）、全部白1回、全機材は全体の15〜20% |
| 終わり | 終わり方が作り込まれ、始まりと対になっている |
| 曲との一致 | 場面の区切りが曲の区切りと一致している |

## 3. 同期（15）

| 観点 | 満点の状態 |
| --- | --- |
| 同期点 | 少なく強い。最大級は3〜4回で、どれも見える出来事が音に合っている（±0.1秒、やや早め寄り） |
| 割り振り | 拍は光、フレーズは水。全部の音に反応していない |
| 追う声部 | 区間ごとに1つで、それが見て分かる |
| 繰り返し | 同じ主題に同じ型が戻る |
| 先取り | 満ちた形を見せたい点は立ち上がり時間だけ前、暗転は水が先・光が時刻 |

## 4. 空間と機材（15）

| 観点 | 満点の状態 |
| --- | --- |
| 主役 | 各場面で主役が1群 |
| 隊形 | 同じ群が同じ形で動く。左右対称が基本 |
| 奥行き | 手前が低く奥が高い。奥の帯が見える |
| 画角 | 主役が x=±40m の内側。端の客席からも成り立つ |
| 物理 | 首振りの速さ、傾けた柱の着水点、重さ（20ms 未満）が守られている |

## 5. 色と光（15）

| 観点 | 満点の状態 |
| --- | --- |
| カラースクリプト | 場面ごとに地の色1つ＋差し色1つ。流れが感情の流れと合う |
| 対比 | 暗さが次の明るさを作っている。山の前に暗さか静けさ |
| 焦点 | 一番明るいのが主役 |
| 目の性質 | 赤系は1段強い。点滅は1秒に3回以下 |
| 水幕 | 黒地・大きな形・縁を避ける。周りの噴水が映像より明るくない |

## 講評の書き方

```
## 講評：<対象>（<日付>、撮影した時刻：...）

| 項目 | 点 | 一言 |
| --- | --- | --- |
| 全体の印象 | 22/30 | ... |
...
| 合計 | 74/100 | |

### 1. 全体の印象
- 良い点：...
- 足りない点：[時刻] ...
- 直し方：...
...

### 直す価値の大きい順
1. ...（どの項目が何点上がる見込みか）
```

撮影して確かめた所と、コードを読んだだけの所を分けて書く。
