# fountain-physics（技術監督）

水は光と違って一瞬では動かない。上がるのに1〜3秒、落ちきるのに3〜9秒、霧は10秒以上残る。演出家が「この音で水が立つ」と書いても、物理を引かないと客には1秒遅れて見える。このスキルは、演出の意図を変えずに、時刻・長さ・強さを物理に合わせて直す。

このプロジェクトの機材とキューの書き方は `.claude/skills/show-director/references/project-api.md`。数値の根拠と出典は `references/physics.md`。

## いつ何を確かめるか

振付を書いたあと、または直すときに、次の6つを順に当てる。どれも「客に見える出来事」の時刻で考える。キューの時刻ではない。

### 1. 立ち上がりの先取り（lead）

見せたい形が「いつ満ちるか」から逆算してキューを置く。花火が開花の時刻から打ち上げ時間を引いて点火するのと同じ考え方。

| 機材 | 全開の高さ | 9割に届くまで | 頂点まで | 止めてから水が消えるまで |
| --- | --- | --- | --- | --- |
| grid | 12m | 1.06秒 | 1.55秒 | 約3.1秒 |
| grid（半分） | 6m | 0.75秒 | 1.10秒 | 約2.2秒 |
| flower | 10m | 0.97秒 | 1.41秒 | 約2.9秒 |
| fan・水幕 | 15m | 1.18秒 | 1.73秒 | 約3.5秒 |
| chaser | 25m | 1.51秒 | 2.22秒 | 約4.5秒 |
| whip | 30m | 1.66秒 | 2.43秒 | 約5.0秒 |
| geyser | 61m | 2.34秒 | 3.45秒 | 約7〜9秒（霧は10秒以上） |

（シミュレーターの弾道モデル `src/core/nozzles.ts` の `flightTime` と同じ式、空気抵抗 kCol=0.04 で計算）

何に合わせるかで先取りの量が変わる。基準は実物：Bellagio・Dubai を0.2秒刻みで測ると、弁は拍と同時か最大0.4秒前に開き、高さは0.5〜1.5秒遅れて届いていた。客は噴き出しを音と結びつけ、頂点の遅れは気にしない。
- **噴き出しの瞬間**（根元が急に光る）を打撃に合わせる：拍と同時〜0.4秒前。ガイザー・チェイサー・pop の「ドン」はこれ。普通はこれでよい
- **満ちた形**（頂点・壁・扇が開ききった形）そのものを和音や頂点に見せたいとき：上の「9割」の秒数だけ前に置く。例外として使う
- **音量への追従**（`follow`）：実物でも水は音量に0.7〜1.5秒遅れる。先読みするなら控えめに 0.3〜0.5秒

どちらが良く見えるかは曲と場面による。迷ったら 0／−0.25／−0.5／−1.0秒の4通りを撮って並べ、目で決める。

### 2. 消すときの先取り（暗転）

暗くしたい時刻から逆算して水を止める。水は止めても空中に残る。
- grid だけなら暗転の約3秒前に止め始める（落ちきるのに約3.1秒）
- その瞬間に見えなくしたいなら、水は先に止め、**光（intensity）を暗転の時刻に落とす**。水は照らされなければ見えない
- geyser を打ったあとは7〜9秒は水と霧が空にある。そのあとに静かな場面を置くなら、リングを落として霧を照らさない（今の `choreography.ts` の最後の処理）
- chaser（25m のショット）も霧を残す。撃った後もリングが点いたままだと、霧の塊が数秒光り続ける。白で撃つと、どの場面でも中央が灰白色に濁る。撃った後はリングを落とす（geyser の `ledAfter` と同じ考え方）
- 背の高い群ほど早く止める：暗転の何秒前に最後の発射・最後の圧力を置けるかは「止めてから水が消えるまで」の列で決まる（whip 約5秒、chaser 約4.5秒、grid 約3秒）

### 3. 首振りの速さ

このシミュレーターは 90°/秒で頭打ちにする（`HEAD_MAX_DEG_S`）。実機は OASE の2軸ドライブで 72°/秒、Disney の特許で 55°/秒以上。頭打ちにかかると、動きは書いた長さより遅れて着く。
- `inOut` のイーズは途中の速さが平均の2倍になる。Δ度を動かすなら `dur ≥ 2 × Δ ÷ 90`（本物らしさを優先するなら ÷72）
  - 例：`spread` −50→+50 の端の1基は100°動く → 2.2秒以上。1.2秒と書くと、拍より約1秒遅れて着く
- 隊形替えは1回に1秒以上かかる。チェイサーと同じ密度で替えない。目安は1小節（2秒）に1回まで

### 4. 傾けた柱は遠くへ落ちる

真上に h まで上がる柱を鉛直から θ 傾けると、最高点は h·cos²θ、着水距離は 2h·sin2θ。
- whip（30m）を40°傾けると約59m先に落ちる。客席は whip の列から約60m
- 客席側（`tilt` 正）や水盤の外へ大きく倒すときは、圧力を下げる（0.5 以下なら着水は半分）
- 左右（`pan`）へ ±55°倒した端の whip（x=±55m）は、舞台の端（±61m）を大きく越える。端の機材ほど外へ倒す角度を控える

### 5. 機材の応答の種類

| 駆動 | 機材 | 応答 | 使い方 |
| --- | --- | --- | --- |
| 可変速ポンプ | grid、whip | 0→100% に約1秒（OASE 仕様） | 1拍より短い高さの変化は見えない。0.25〜0.5秒より細かい起伏は、高さではなく光で打つ |
| 開閉弁 | flower、fan | 開 0.2秒・閉 0.25秒（`VALVE_OPEN_S`） | 出し入れはスパッと。ゆっくりのランプは「拡大縮小」に見える |
| 空気式（シューター） | chaser、geyser | ほぼ瞬時に出て瞬時に止まる | 打撃。1基の連射は 0.8秒以上空ける |
| LED | 全機材 | 色0.6秒・明るさ0.9秒・点く0.12秒が下限（`cues.ts` が強制）。色はノズルから先へ 45 m/s で上がる（最大1秒） | 拍・打撃・暗転は光で。ただし一瞬では変わらない |

### 6. 重さ（描画の予算）

1280×720 で1フレーム 20ms 未満を守る。重いのは霧：
- geyser の霧と水幕（山を含む）が同時に出る場面が一番重い。geyser 10本＋山3つは超える
- 打つ本数を減らす（`geyser[0-9:3]` で4本）か、水幕の出ている間は geyser を打たない
- 確かめ方：`node scripts/show-shot.mjs --t=<秒> --perf`

## レビューの出し方

振付（`src/show/choreography.ts` かエディタの JSON）を見て、問題ごとに次の形で返す。直し方まで書く。

```
[時刻 / 対象] 何が起きるか（客にどう見えるか）
  原因：物理のどの項目か（数値）
  直し方：キューの t / dur / 圧力をこう変える
```

例：
```
[62.25s / whip spread −50→50 dur 1.2] 扇が開ききるのは 64.4s。トゥッティの頭から2秒遅れて見える
  原因：100°を1.2秒（inOut の途中は167°/秒）。上限 90°/秒で約2.2秒に延びる
  直し方：開ききった形を 62.25s に見せたいなら t=60.0、dur=2.2。噴き出しの勢いで合わせるなら、扇は前の小節のうちに作っておき、62.25s は圧力 0.5→1 の pulse で打つ
```

## このスキルがしないこと

何を見せるか、どの色か、どの場面を山にするかは決めない。物理に合わない演出を見つけたら、意図を保つ直し方を出し、意図そのものを変える必要があるときは演出側（show-director）に返す。

## 本物らしさ（`real` モード）

`real` は機材どおりを守る（ユーザーと合意済み）。新しい光を足す提案はしない。物理の観点で本物らしさを上げる余地があれば、`references/physics.md` の「実機との違い」から挙げる。
