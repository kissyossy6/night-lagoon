## 実測：実際のショーの時間差

Bellagio・Dubai の5本を0.2秒刻みで見て測った（`docs/show-knowledge/v1-bellagio-dubai.md`）。

| 出来事 | 音の立ち上がり | 水・照明 | 差 |
| --- | --- | --- | --- |
| Dubai TTSG 最初の一撃 | 25.84 | 水が見え始め 25.4、最大高さ 26.6頃 | 水が0.4秒先、高さは0.8秒後 |
| Dubai TTSG 暗転後のサビ | 68.20 | 単発が見え始め 68.1、全部が高く 69.5頃 | 0.1秒先、高さは1.3秒後 |
| Dubai Baba Yetu 合唱の入り | 24.49 | 青→白 24.4 | 0.1秒先 |
| Dubai Baba Yetu 2:18 の戻り | 139.01 | 青→白 138.8 | 0.2秒先 |
| Bellagio Viva ブレイク | 96.80 | 弧が消えて見える 97.3〜97.5 | 0.5秒後（落ちる時間を含む） |
| Bellagio Viva 中央のシューター | — | 98.2 に出始め 99.6 で最高 | 伸びるのに1.4秒 |
| Bellagio Viva 照明の瞬断 | 124.19 | 123.75〜124.0 に消え 124.25 に点く | 消すのは休符、点けるのは拍 |

- 照明は拍とほぼ同時（±0.2秒）
- 水の弁は拍と同時か最大0.4秒前。高さは0.5〜1.5秒遅れて届く
- コマ単位では音のオンセットと映像の変化の相関は弱い（r=0.01〜0.27）。水は拍ごとには動かない
- 1秒でならした音量と水の明るい面積は r=0.33〜0.49 で、水が0.7〜1.5秒遅れたときに一番合う。水はフレーズの大きさに付いていく
- 多場面ショー（WoC 2010・万博）でも、大きな一撃は拍に合わせる（16個中6個が ±0.2秒。残りは客席の録音の雑音で判定できず）

## 音楽の要素 → 機材（このショー）

| 要素 | 読み方 | 機材・パラメータ | 先取り |
| --- | --- | --- | --- |
| セクション | 音量の段差、自己相似、耳 | 場面の色・使う群・水幕 | 色 0、新しい群は立ち上がり分 |
| フレーズ | 旋律の休み、ノベルティ | whip の隊形、grid の波の向き、fan の開閉 | 動き時間の半分 |
| ダウンビート | 拍の追跡かタップ | chaser、LED パルス、リング | 水は 0、光も 0 |
| オンセット | spectral flux | LED フラッシュ、手前の grid の pop | 0 |
| 音量 | RMS を 0.5〜1秒でならす | grid 全体の高さ、本数、山 | 約1秒 |
| クレッシェンドの頂点 | 音量の極大 | 全機材が満ちる、geyser | 立ち上がり分 |
| 旋律の音高 | 音高推定 | whip の tilt、波の山を上へ | 動き時間の半分 |
| 柔らかい音色 | スペクトル重心が低い | 単柱、ゆっくりした sway | — |
| 硬い音色 | 重心・平坦度が高い | fan・flower・霧、chaser | — |
| 低音 | 低域の音量 | 奥の帯・山・geyser の量 | 立ち上がり分 |
| 無音 | 音量が床 | 全消灯 | 水 −3秒、光 0 |

## 今の実装への示唆（2026-10-26 時点）

- pops・chases・geyser がオンセットの時刻ちょうど（隊形はフレーズの頭に置く形に変えた）。実物（弁は拍と同時〜0.4秒前）に近いので大きく変える必要はない。0.1〜0.3秒早める余地はある
- `follow` の遅れ（約1.1〜1.3秒）は実物の範囲（0.7〜1.5秒）。先読みの引数を足すなら控えめに（0.3〜0.5秒）
- 3帯の follow（奥＝低・中＝中・手前＝高）はカラーオルガン。全体の高さ＝ならした音量、帯の差＝場面ごとの固定の形、低音＝本数や山・geyser の量、高域の打撃＝手前の帯と光、に組み替える
- 解析のならし（上がり 30ms・下がり 200ms）は水には速すぎる。水の高さに使うなら上がり 0.15〜0.3秒・下がり 0.5〜1秒（推測）
- オンセットの上に拍とフレーズの層を作る。チェイサーとウィップは拍・小節頭に置き、オンセットは「打つかどうか」と強さの判断に使う。テンポの揺れる曲は、エディタで人がタップして拍を記録する機能が確実
- `sync-check` を見える出来事で測るように直す
