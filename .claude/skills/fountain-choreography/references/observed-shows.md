# 実際のショーで観察した型

実際のショー映像を1秒ごと（要所は0.2秒ごと）に見て拾った型。時刻は動画の時刻。原本と代表コマは `docs/show-knowledge/`（v1＝Bellagio・Dubai、v3＝WoC 2010・万博、video-review＝WoC ONE）と `shots/show-analysis/`。

## 1曲ショー（Bellagio・Dubai、WET）

| 型 | 例 | 音楽のどこで | このショーでの作り方 |
| --- | --- | --- | --- |
| 前奏は小さく1か所、色付き | Dubai Baba Yetu 0:02–0:24 青い中央、Dubai TTSG 0:00–0:25 赤い点、Bellagio MHWGO 0:20 右端だけ | 前奏 | grid の中央の数基か種火、単色。whip・geyser・水幕は出さない |
| 入りの一撃（色と量を同じ拍で替える） | Baba 0:24.5、Dubai TTSG 0:25.4 | 合唱・オーケストラが入る所 | 拍の上で色を白（か主の色）へ、同時に grid 全帯と fan を出す |
| キメに1つずつ、場所を替えて | Bellagio Viva 0:11–0:17 | 前奏のキメ | 左・右・中央の群を一打ずつ（pulse） |
| 中央から外へ | Viva 0:30–0:36、Bellagio TTSG 2:55–3:17 | 盛り上がりの始め | stagger `center` |
| 左右対称の塔＋中央 | Viva 0:42、1:11、2:03 | サビ | 左右の弧の chaser＋中央の geyser 1本 |
| 一方向の傾斜の波（片側が高い） | Bellagio TTSG 0:39–0:47、2:00、3:17–3:37 | 長い音・サビ | 帯に `index` の時差で高さの勾配（`ramp` があれば一発） |
| 交差・格子 | Bellagio TTSG 0:20–0:26 | 歌い出し、旋律だけの所 | whip `spread` +a→−a |
| 円の花びら（内倒し・外倒し） | Dubai TTSG 0:36–0:41、Baba 0:26–0:35 | 節の途中の揺れ | chaser リング、flower `bloom` の開閉 |
| 線の上を走る | Baba 0:36–0:43、1:20–1:37、3:00– | つなぎ、後奏 | chaser `chase`、grid の帯に1基ずつ |
| 静かな節は1か所だけ | Bellagio TTSG 2:10–2:55 中央、Dubai TTSG 2:21– 腕だけ、Baba 1:58– 青い中央 | 2番 | 中央の grid だけ、または whip だけ。全体を低くするより強い |
| 引いてから1本だけ高く | Viva 1:37 ブレイク → 1:38 中央のシューター | ブレイク | 全部を切り、中央の geyser 1本 |
| 暗転→全開 | Dubai TTSG 1:04–1:08 → 1:08.2、Viva 2:18.5 → 2:19.25 | 区切り、最後の一撃 | 水を約3秒前に止め、光を暗転の時刻に落とし、拍の上で全開 |
| 照明だけの瞬断（水は出たまま） | Viva 2:03.8、2:07.3 | 休符・キメ | intensity を休符で0、拍で戻す。水は触らない |
| 霧の余韻 | Bellagio TTSG 4:03–4:11、Viva 2:21– | 曲の終わり | 最後の一撃の後、霧（mist・haze）を3〜5秒残す |
| 前奏と同じ形で閉じる | Baba 3:00– 青い中央 | 後奏 | 始まりの絵をそのまま戻す（ブックエンド） |

数値：区間は10〜25秒（速い曲で平均11秒、バラードで約22秒）、形は2〜6秒で替わる。最も高い水は1曲2〜3回。暗転は1曲1〜4回。

## 多場面ショー（World of Color、万博「アオ」）

| 型 | 例 | 使いどころ |
| --- | --- | --- |
| 投影の物語では噴水を止める | WoC 2010 のニモ・WALL-E（光っている面積 6〜9%）、万博の少年が門に立つ153秒の谷 | 水幕の物語、最大の山の直後の谷 |
| 全面は1色 | WoC 2010 の赤一色の全面3回（強い曲に毎回）、青一色 | 歌の場面 |
| 時間方向の多色 | WoC 2010・万博のフィナーレ：全面を2秒ごとに単色で切り替え | フィナーレ |
| 虹は「絵」として一か所 | 万博：霧の弧に虹を投影する62秒の静かな場面 | 頂点の手前の見せ場 |
| 一撃の前の短い暗 | 2〜3分に1回、3〜7秒 | 山の直前 |
| 単独の大柱を最初と最後に | WoC 2010：序曲の中央の青い大柱（4%）と最後（99%） | ブックエンド |
| 全機材の初登場を遅らせる | 万博：最初の全面は本編の41% | 物語の比重が大きいショー |
