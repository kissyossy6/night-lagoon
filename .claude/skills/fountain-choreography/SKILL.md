# fountain-choreography（振付）

噴水の振付は「群舞」の振付に近い。一基一基は単純な動きしかできないが、並び順に時差をかけ、左右を鏡写しにし、隊形を保って動かすと、客には一つの大きな生き物の動きに見える。逆に、同じ群がばらばらに動くと、ただの乱れに見える。

このプロジェクトの機材・マクロ・書き方は `.claude/skills/show-director/references/project-api.md`。動きの語彙の辞典は `references/vocabulary.md`。実際のショーで観察した型は `references/observed-shows.md`。

## 場面を振り付ける手順

show-director の構成表（区間・感情・密度・山場）と music-to-water の音楽地図（追う声部・同期点）を受け取ってから始める。無ければ先に作ってもらう。

### 1. 役を割り振る

各場面で **主役は1群**。1〜2群が伴奏、残りは低く背景か、消す。全部の群を同時に主役にするのは山場だけ。

| 役 | やること | 例 |
| --- | --- | --- |
| 主役 | 追う声部（旋律・打撃・独奏）を体で表す | 旋律を whip の隊形で、打撃を chaser で |
| 伴奏 | 主役を支える一定の動き | grid の低い波、fan の開閉 |
| 背景・土台 | 場面の色と床を作る。目を引かない | grid の帯を低く一定に（奥を高く） |
| 休み | 出さない。次の出番を新鮮にする | 物語の間の fan・flower |

機材の性格と向く役：grid＝画素・土台、whip＝踊り手（旋律・レガート）、chaser＝走る（打楽器・細かい音符）、fan＝開く（区切りの決め）、flower＝咲く（頂点・一輪）、geyser＝撃つ（最大の山だけ）、水幕＝物語。

### 2. 隊形を決めてから動かす

隊形（形）を先に決め、動きはその形の「変わり方」として書く。今の隊形のマクロ：
- `spread` −a→+a：外へ開く扇。+a→−a：中央で交差
- `lean`：全員が同じ角度へ。時差をかけると端から倒れる波
- `sway`：そろって揺れる（時差をかけると軌跡が交差して網目になり、乱れに見える。ゆっくり大きく、そろえて）

**左右対称を基本にする**：中央から外（`order: 'center'`）、外から中央（`'edges'`）、鏡写し。崩すのは乱れや対立を表したいときだけ。

### 3. 時差（stagger）で動きの向きを作る

並び順に時差をかけると、静止した機材が「流れ」になる。
- `index`／`reverse`：左から右／右から左へ掃く。フレーズの方向感
- `center`：中央から外へ広がる。始まり・開放・波紋
- `edges`：外から中央へ集まる。終わり・集中・溜め
- `random`：きらめき。隊形の場面では使わない

時差の大きさは、群全体を走り抜ける時間で考える：0.2〜0.4秒で「一斉に、でも生きている」、1〜2秒で「波が渡る」、4秒以上で「ゆっくり目覚める」。順位の数え方は project-api.md の2章（`center` は順位が半分になる）。

**落とし穴**：複数の帯や弧をつないだグループ（`grid` 全体、`chaser` 全体）に `center`／`edges`／`rainbow` をかけると空間とずれる（fountain-layout）。帯・弧ごとに書く。

### 4. 繰り返しを型にする

同じ主題が戻ってきたら、最初に使った隊形・色・機材の順を戻す。客は「さっきのあれだ」と気づき、構成が見える（ChoreoMaster の規則）。変奏したいなら、同じ型を一段大きく（本数・高さ・広がりを増やす）。

### 5. 息をさせる

- 強い区間が20〜30秒続くなら、色・隊形・高さのどれか一つを変えて目を新しくする（WET の Kopik は「強いのに疲れさせない」ことを課題に挙げた）
- 動きを止める「静止（tableau）」も振付。音の休みで隊形のまま止めると、次の動きが効く
- 機材を出さない時間を作る。出ずっぱりの群は、出ても驚きがない

### 6. 物理で確かめる

書いたら fountain-physics の6項目（先取り、暗転、首振りの速さ、傾けた柱、応答、重さ）を当てる。特に、隊形替えの `dur` は `2 × 角度 ÷ 90` 以上。

## 語彙の早見表

| 型 | 形 | 向く音楽 | 作り方 |
| --- | --- | --- | --- |
| Sweep（掃く） | 列が端から順に倒れる | 旋律の大きなフレーズ | whip `lean` ±40、stagger 0.04 `index` |
| Fan（扇） | 中央から外へ開く | 和音の広がり、決め | whip `spread` −a→+a |
| Cross（交差） | 左右が中央で X | 緊張、2つの声 | `spread` +a→−a |
| Chase（追いかけ） | 光と水が弧を走る | 打楽器、細かい音符 | chaser `chase` speed 18〜30、左右交互 |
| Swirl（渦） | リングを回り続ける | 回転、上昇 | chaser リング `chase` laps 2〜4 |
| Wave（波） | 高さの山が列を伝わる | ゆったりした拍、流れ | 帯ごとに `wave` stagger `index`→次は `reverse` |
| Ripple（波紋） | 中央から外へ広がる | 一音の余韻 | `pulse` stagger `center` |
| Gather（集まる） | 外から中央へ、外から消える | 終わり、溜め | `set`/`off` stagger `edges` |
| Hit（打つ） | 全部が同時に一瞬立つ | 強拍、クラッシュ | `pulse` hold 0.12〜0.4、時差なし |
| Shoot（撃つ） | 太い柱を1発 | 最大のアクセント | geyser `pulse` hold 1〜2、白 |
| Bloom（咲く） | 輪が外へ開く | 頂点、解決、静かな一輪 | flower `bloom` to 18〜28 |
| Swell（満ち引き） | 高さが音量で満ち引き | 長い音、パッド | `follow`（先取りつき） |
| Call & response | 左右が交互に答える | 2つの楽器の掛け合い | 左右の弧・whip の左右半分に交互 |
| Tableau（静止） | 隊形のまま止める | 休み、溜め | 動きのキューを入れない |
| Pilot lights（種火） | 低い水の光の点 | 始まりと終わり、暗闇 | grid pressure 0.04 |

詳しい作り方と、まだマクロがない型（Bounce・Cascade・mirror・alternate）は `references/vocabulary.md`。

## チェックリスト（レビューで使う）

- [ ] 各場面で主役が1群に決まっている（山場を除く）
- [ ] 同じ群が同じ形で動いている（そろっているか、規則正しくずれている）
- [ ] 左右対称が基本になっていて、崩すところに理由がある
- [ ] 時差の向き（index／center／edges）が音楽の向き（上昇・開放・収束）と合っている
- [ ] 同じ主題には同じ型が戻っている
- [ ] 強い区間が30秒以上同じ見た目のまま続いていない
- [ ] 出ずっぱりの群がない。休んでいる時間がある
- [ ] 隊形替えが1小節（2秒）に1回を超えていない
- [ ] 帯・弧をつないだグループに `center`／`edges`／`rainbow` をかけていない
- [ ] fountain-physics の確認を通した

## 出すもの

場面ごとに、役の表（主役・伴奏・背景・休み）と隊形の流れを短く書いてから、`choreography.ts` のキューにする。キューには、何を表しているかを1行のコメントで添える（今のコードと同じ書き方）。
