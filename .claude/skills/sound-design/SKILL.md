# sound-design（音を作る）

耳で「それっぽい」音を作ると、作った人のスピーカーでしか成り立たない。最初の花火の音は 35〜60 Hz の正弦波が主で、ノートパソコンでは鳴らず「ちゃっちい」と言われた。実物の録音を測ると、ドーンの重さは 90〜900 Hz にあった。**数字で作り、数字で確かめ、最後に耳（ユーザー）で決める。**

録音そのものはショーで鳴らさない（ライセンスと、同じ音の繰り返しを避けるため）。録音は「手本の数字」を取るためだけに使う。

## 流れ

### 1. 録音を集める

- 自由に使える所から：Wikimedia Commons（パブリックドメイン・CC）。Freesound はアカウントが要るので、ユーザーが自分で落として `references/sounds/<音>/` に置く
- 落とす前に、ファイル名・出典・大きさ・ライセンスを並べてユーザーに聞く
- 置き場は `references/sounds/<音>/`、出典は同じ所の `CREDITS.md`（`sources.json` に機械で読める形でも）
- 手本は「客席で聞く音」に近いもの：距離・場所（湖の上か、街中か）が近い録音を選ぶ。近所の爆竹と大会の割物は別の音

### 2. 1つずつの音を拾って測る（`scripts/sound/analyse.py`）

- ffmpeg でモノラル 24 kHz にして、10 ms ごとに10の帯域（25 Hz〜11 kHz）の音量を測る
- 音の始まり：低い帯域が直前より 12 dB 以上跳ね上がった所
- **単独の音だけ使う**：前 1 秒・後 2.5 秒に他の音が始まらないもの。重なった音の尾は他の音の頭
- 背景（直前 0.5 秒の帯域ごとの音量）を電力で引く。引かないと、尾が客席のざわめきで平らになる
- 近くてはっきりした音だけ（背景より 24 dB 以上、`--min-snr=24`）で手本を作る。遠い音は高い所が削れている
- 測る数字：帯域ごとの音量の時間変化（中央値）、立ち上がり、-20/-40 dB までの時間、尾の揺らぎ（大きさと周期）

### 3. 数字から作る（`scripts/sound/fit.py` → `src/audio/<音>.json`）

- 帯域ごとにノイズを帯域フィルタに通し、測った音量の時間変化を掛けて足す（帯域ごとのノイズの再合成）。録音の波形は使わないので、毎回違う、オリジナルの音になる
- 測った曲線は、ならして（50 ms）、最大の後は下がるだけにする。揺らぎ（反響の塊）は別に、測った大きさと周期の乱数で足す
- 左右は、頭は同じノイズ（音の位置がわかる）、尾は別々のノイズ（広がる）
- 大きさ（号数）・距離で変える所は、測っていなければ「目で（耳で）決めた」と書く
- 値は1か所（`src/audio/<音>.json` と、その横の定数）に置く

### 4. 作った音を同じ解析にかけて比べる（`scripts/sound/compare.py`）

- ブラウザで作った音を書き出し（`scripts/sound/render.mjs`）、手本と同じ物差しで測る
- 帯域ごとに「手本｜作った音」の曲線を重ねた図を作る。ずれた帯域の強さ（trim）を直して、もう一度
- 合格の目安：ピークの帯域の並びが手本と ±3 dB、-20 dB までの時間が ±30%

### 5. 聴き比べで渡す

- 「今 → 案」を同じ所で続けて（間に無音 1.5 秒）、曲と水音込みで。単独の音も
- 図（帯域の曲線、スペクトログラム）も添える。ユーザーが耳で決める
- 前の音はバックアップに残す

## やってはいけないこと

1. 耳だけで作って「迫力が出た」と言う（自分の再生環境の話にすぎない）
2. 50 Hz より下に重さを置く（多くのスピーカーで鳴らない）
3. 録音をそのまま鳴らす（ユーザーが「オリジナルを作って」と言った。ライセンスの表示も要る）
4. 尾を長くして壁にする（1発ずつのドンが聞き分けられなくなる。測った減衰に合わせる）
